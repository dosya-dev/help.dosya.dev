Use this workflow to move a folder to Deleted items in the intended workspace.

Deleting a folder sends its subtree to Deleted items. Treat the folder and its children as one recovery unit until you verify the trash state.

## Before you start

- Open Files → Delete in the current released Dosya client.
- Confirm the active account and workspace, then identify one disposable folder tree.

## Steps: move a folder to Deleted items

1. Open Files → Delete and confirm the active workspace.
2. Select one disposable folder tree and check its name or identifying details.
3. Review the folder and confirm deletion.
4. Verify that the folder and its children appear together in Deleted items.

**Safety note.** Review names and deletion details in Deleted items before restoring or cleaning up.

## Verify the result

Open Deleted items and confirm the folder name and representative children are present before any permanent cleanup.

## Expected result

The workflow completes for the controlled test and the folder and its children appear together in Deleted items.

## Troubleshooting

**The expected control is missing.** Return to Files → Delete, confirm the active workspace and check that your role permits the action.
