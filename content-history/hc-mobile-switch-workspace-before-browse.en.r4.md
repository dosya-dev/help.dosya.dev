This guide covers **Switch mobile workspaces before browsing** in Dosya. The main action is to open the workspace switcher, choose the intended workspace, and verify its name before opening files; the decisive check is whether the browser shows files from the selected workspace.

## Before you start

- Open the Dosya mobile file browser and search in the current released client.
- Confirm the active account and workspace, then identify account with access to several workspaces.

## Steps: switch mobile workspaces before browsing

1. Open the Dosya mobile file browser and search and confirm the active account and workspace.
2. Locate account with access to several workspaces and verify its name or identifying details.
3. Open the workspace switcher, choose the intended workspace, and verify its name before opening files.
4. Confirm that the browser shows files from the selected workspace.

**Safety note.** Confirm the workspace and folder breadcrumb before acting on a mobile search result.

## Verify the result

After completing the steps, check the expected result: The browser shows files from the selected workspace.

## Expected result

The controlled workflow completes and the browser shows files from the selected workspace.

## Troubleshooting

**The expected control is missing.** Return to the Dosya mobile file browser and search, confirm the active workspace, and check that your role and client version support the action.
