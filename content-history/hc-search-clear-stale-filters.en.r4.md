This guide covers **Clear stale search filters** in Dosya. The main action is to inspect every active scope, type, date, or other available filter, clear them, and run the query again; the decisive check is whether the search reflects the current query without unintended filtering.

## Before you start

- Open the Dosya file search in the current released client.
- Confirm the active account and workspace, then identify search returning unexpectedly few or no results.

## Steps: clear stale search filters

1. Open the Dosya file search and confirm the active account and workspace.
2. Locate search returning unexpectedly few or no results and verify its name or identifying details.
3. Inspect every active scope, type, date, or other available filter, clear them, and run the query again.
4. Confirm that the search reflects the current query without unintended filtering.

**Safety note.** Use folder context and file details to distinguish similar results.

## Verify the result

After completing the steps, check the expected result: The search reflects the current query without unintended filtering.

## Expected result

The controlled workflow completes and the search reflects the current query without unintended filtering.

## Troubleshooting

**The expected control is missing.** Return to the Dosya file search, confirm the active workspace, and check that your role and client version support the action.
