This guide covers **Select nonadjacent files** in Dosya. The main action is to use the row checkboxes or supported additive-selection gesture and verify each highlighted item; the decisive check is whether only the individually chosen rows contribute to the selection count.

## Before you start

- Open a Dosya file or search-results list in the current released client.
- Confirm the active account and workspace, then identify several separated disposable rows.

## Steps: select nonadjacent files

1. Open a Dosya file or search-results list and confirm the active account and workspace.
2. Locate several separated disposable rows and verify its name or identifying details.
3. Use the row checkboxes or supported additive-selection gesture and verify each highlighted item.
4. Confirm that only the individually chosen rows contribute to the selection count.

**Safety note.** Review the selection count and every selected row before starting a batch action.

## Verify the result

After completing the steps, check the expected result: Only the individually chosen rows contribute to the selection count.

## Expected result

The controlled workflow completes and only the individually chosen rows contribute to the selection count.

## Troubleshooting

**The expected control is missing.** Return to a Dosya file or search-results list, confirm the active workspace, and check that your role and client version support the action.
