This guide covers **Map Dosya WebDAV in Windows** in Dosya. The main action is to enter the documented WebDAV address and restricted credentials, then finish the wizard; the decisive check is whether file Explorer opens the permitted remote location.

## Before you start

- Open a WebDAV client connected to Dosya and locate the Windows network-location wizard.
- Confirm the active account and workspace, then identify Windows network-location wizard.

## Steps: map Dosya WebDAV in Windows

1. Confirm the account and workspace in a WebDAV client connected to Dosya when reviewing the Windows network-location wizard.
2. Locate Windows network-location wizard and verify its name or identifying details.
3. Enter the documented WebDAV address and restricted credentials, then finish the wizard.
4. Confirm that File Explorer opens the permitted remote location.

**Safety note.** Use a restricted WebDAV key and expect client behavior to vary by operating system.

## Verify the result

After completing the steps, check the expected result: File Explorer opens the permitted remote location.

## Expected result

The controlled workflow completes and File Explorer opens the permitted remote location.

## Troubleshooting

**The expected control is missing.** If the required control is missing for the Windows network-location wizard, check the active workspace, your role and the client version.
