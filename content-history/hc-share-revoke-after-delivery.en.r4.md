This guide covers **Revoke a sharing link after delivery** in Dosya. The main action is to review recent access, choose Revoke, and confirm; the decisive check is whether the previous URL no longer opens the shared files.

## Before you start

- Open a Dosya sharing link in the current released client.
- Confirm the active account and workspace, then identify link whose delivery is complete.

## Steps: revoke a sharing link after delivery

1. Open a Dosya sharing link and confirm the active account and workspace.
2. Locate link whose delivery is complete and verify its name or identifying details.
3. Review recent access, choose Revoke, and confirm.
4. Confirm that the previous URL no longer opens the shared files.

**Safety note.** Test the link in a private browser window before sending it to real recipients.

## Verify the result

After completing the steps, check the expected result: The previous URL no longer opens the shared files.

## Expected result

The controlled workflow completes and the previous URL no longer opens the shared files.

## Troubleshooting

**The expected control is missing.** Return to a Dosya sharing link, confirm the active workspace, and check that your role and client version support the action.
