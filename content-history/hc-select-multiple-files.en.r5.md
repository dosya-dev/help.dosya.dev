Use this workflow to select multiple files safely in the intended workspace.

The visible selection count is the safest check before a batch move or delete. Filters and pagination can make the selected set less obvious.

## Before you start

- Open Files and locate several harmless test files.
- Confirm the active account and workspace, then identify several harmless test files.

## Steps: select multiple files safely

1. Confirm the workspace in Files when reviewing several harmless test files.
2. Select several harmless test files and check its name or identifying details.
3. Enter multi-select mode and select only the intended rows or cards.
4. Verify that the selection count and highlighted items agree.

**Safety note.** Review the highlighted items and selection count before applying a batch action.

## Verify the result

Compare the highlighted rows or cards with the count, then remove any unintended item before choosing a batch action.

## Expected result

The workflow completes for the controlled test and the selection count and highlighted items agree.

## Troubleshooting

**The expected control is missing.** If the required control is missing for several harmless test files, check the active workspace, your role and the client version.
