This guide covers **Load older Dosya notifications** in Dosya. The main action is to choose Load more and wait for the next cursor page; the decisive check is whether older items append without duplicating the current notifications.

## Before you start

- Open Notifications in the current released client.
- Confirm the active account and workspace, then identify Load more control below the current inbox page.

## Steps: load older Dosya notifications

1. Open Notifications and confirm the active account and workspace.
2. Locate Load more control below the current inbox page and verify its name or identifying details.
3. Choose Load more and wait for the next cursor page.
4. Confirm that older items append without duplicating the current notifications.

## Verify the result

After completing the steps, check the expected result: Older items append without duplicating the current notifications.

## Expected result

The controlled workflow completes and older items append without duplicating the current notifications.

## Troubleshooting

**The expected control is missing.** Return to Notifications, confirm the active workspace, and check that your role and client version support the action.
