This guide covers **Enable browser push notifications** in Dosya. The main action is to select it and allow notifications in the browser permission prompt; the decisive check is whether browser push stays enabled and the browser has permission for Dosya.

## Before you start

- Open Profile > Notifications in the current released client.
- Confirm the active account and workspace, then identify Enable browser notifications control.

## Steps: enable browser push notifications

1. Open Profile > Notifications and confirm the active account and workspace.
2. Locate Enable browser notifications control and verify its name or identifying details.
3. Select it and allow notifications in the browser permission prompt.
4. Confirm that Browser push stays enabled and the browser has permission for Dosya.

**Safety note.** Some security and service messages are always on even when optional groups are disabled.

## Verify the result

After completing the steps, check the expected result: Browser push stays enabled and the browser has permission for Dosya.

## Expected result

The controlled workflow completes and Browser push stays enabled and the browser has permission for Dosya.

## Troubleshooting

**The expected control is missing.** Return to Profile > Notifications, confirm the active workspace, and check that your role and client version support the action.
