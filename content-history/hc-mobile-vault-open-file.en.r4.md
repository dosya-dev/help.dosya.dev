This guide covers **Open a Vault file on mobile** in Dosya. The main action is to select it and wait for local download and decryption; the decisive check is whether the file opens in the protected mobile viewer.

## Before you start

- Open Vault in the Dosya mobile app in the current released client.
- Confirm the active account and workspace, then identify supported encrypted file.

## Steps: open a Vault file on mobile

1. Open Vault in the Dosya mobile app and confirm the active account and workspace.
2. Locate supported encrypted file and verify its name or identifying details.
3. Select it and wait for local download and decryption.
4. Confirm that the file opens in the protected mobile viewer.

**Safety note.** Keep the app updated, the device locked, and the recovery key stored offline.

## Verify the result

After completing the steps, check the expected result: The file opens in the protected mobile viewer.

## Expected result

The controlled workflow completes and the file opens in the protected mobile viewer.

## Troubleshooting

**The expected control is missing.** Return to Vault in the Dosya mobile app, confirm the active workspace, and check that your role and client version support the action.
