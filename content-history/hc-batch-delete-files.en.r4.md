Use this workflow to delete multiple items together in the intended workspace.

A batch delete can affect many items at once. Use Deleted items as the recovery checkpoint before any permanent cleanup.

## Before you start

- Open Files → Delete in the current released Dosya client.
- Confirm the active account and workspace, then identify a disposable selection.

## Steps: delete multiple items together

1. Open Files → Delete and confirm the active workspace.
2. Select a disposable selection and check its name or identifying details.
3. Review the selected names and send the batch to Deleted items.
4. Verify that only the reviewed items leave the active folder.

## Verify the result

Review the source folder and Deleted items, confirming that only the selected names moved and unrelated files remain.

## Expected result

The workflow completes for the controlled test and only the reviewed items leave the active folder.

## Troubleshooting

**The expected control is missing.** Return to Files → Delete, confirm the active workspace and check that your role permits the action.
