Use this workflow to check where a file came from in the intended account or workspace.

Check the workspace, folder path and identity of a recently uploaded or imported file. Test a recently uploaded or imported file with disposable data and compare source and destination after refreshing.

## Before you start

- Open Files → Details in the current released Dosya client.
- Confirm the active account and workspace, then identify a recently uploaded or imported file.

## Steps: check where a file came from

1. Open Files → Details and confirm the active workspace.
2. Select a recently uploaded or imported file and check its name or identifying details.
3. Review its source, uploader and created information when available.
4. Verify that the displayed origin agrees with the workflow that created the file.

**Safety note.** Confirm the selected file and workspace before changing or copying it.

## Verify the result

Verify that the displayed origin agrees with the workflow that created the file.

## Expected result

The workflow completes for the controlled test and the displayed origin agrees with the workflow that created the file.

## Troubleshooting

**The expected control is missing.** Return to Files → Details, confirm the active workspace and check that your role permits the action.
