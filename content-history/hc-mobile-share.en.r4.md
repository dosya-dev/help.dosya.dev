Create the delivery from the cloud file, then use the phone sharing sheet only after access settings and target are verified.

A mobile share sheet sends the link through another application; it does not change the Dosya link policy. Configure and test access before sending.

## Steps: share a dosya file from your phone

1. Open the file in the correct workspace.
2. Choose Share and review link settings.
3. Set expiry, password or recipient restriction as needed.
4. Generate and copy the link.
5. Test it in a signed-out browser.
6. Send the tested link through the chosen mobile app.

## Verify the result

Open the link while signed out, confirm password or recipient controls and verify the intended file can be viewed or downloaded according to policy.
