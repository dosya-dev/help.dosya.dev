This guide covers **Verify an extension save in Dosya** in Dosya. The main action is to open the saved item, compare its name, type, destination, and preview with the source; the decisive check is whether the captured content is present in the intended folder.

Keep the browser profile, signed-in account, site permission, destination workspace, and folder in view while you work.

## Before you start

- Open the Save to Dosya browser extension in the current released client.
- Confirm the active account and workspace, then identify extension success state with a saved item link.

## Steps: verify an extension save in Dosya

1. Open the Save to Dosya browser extension and confirm the active account and workspace.
2. Locate extension success state with a saved item link and verify its name or identifying details.
3. Open the saved item, compare its name, type, destination, and preview with the source.
4. Confirm that the captured content is present in the intended folder.

## Verify the result

After completing the steps, check the expected result: The captured content is present in the intended folder.

Open the saved result in Dosya and compare it with the selected page, screenshot, or file. Check the active browser profile, site permission, extension session, destination access, and the visible extension error.

## Expected result

The controlled workflow completes and the captured content is present in the intended folder.

## Troubleshooting

**The expected control is missing.** Return to the Save to Dosya browser extension, confirm the active workspace, and check that your role and client version support the action.
