Use this workflow to add several files to a group in the intended account or workspace.

The main checks are the active workspace, folder path and target item. Start with one harmless item and compare the source and destination after refreshing the view.

## Before you start

- Open Files → Add to group in the current released Dosya client.
- Confirm the active account and workspace, then identify multiple related test files.

## Steps: add several files to a group

1. Open Files → Add to group and confirm the active workspace.
2. Select multiple related test files and check its name or identifying details.
3. Choose an existing group and apply it to the selection.
4. Verify that the group contains each selected item without duplicates.

## Verify the result

Verify that the group contains each selected item without duplicates.

## Expected result

The workflow completes for the controlled test and the group contains each selected item without duplicates.

## Troubleshooting

**The expected control is missing.** Return to Files → Add to group, confirm the active workspace and check that your role permits the action.
