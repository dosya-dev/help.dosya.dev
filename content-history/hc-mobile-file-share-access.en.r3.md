This guide covers **Share a mobile file with the correct access** in Dosya. The main action is to create or select the appropriate link settings, verify them, and send the link through the intended channel; the decisive check is whether the recipient receives access consistent with the selected controls.

## Before you start

- Open the Dosya mobile file browser in the current released client.
- Confirm the active account and workspace, then identify file sharing action in the mobile app.

## Steps: share a mobile file with the correct access

1. Open the Dosya mobile file browser and confirm the active account and workspace.
2. Locate file sharing action in the mobile app and verify its name or identifying details.
3. Create or select the appropriate link settings, verify them, and send the link through the intended channel.
4. Confirm that the recipient receives access consistent with the selected controls.

## Verify the result

After completing the steps, check the expected result: The recipient receives access consistent with the selected controls.

## Expected result

The controlled workflow completes and the recipient receives access consistent with the selected controls.

## Troubleshooting

**The expected control is missing.** Return to the Dosya mobile file browser, confirm the active workspace, and check that your role and client version support the action.
