This guide covers **Recheck mobile permissions after an OS update** in Dosya. The main action is to review Dosya permissions in device settings, restore only required access, reopen the app, and retest one action; the decisive check is whether the affected feature works with an understood permission scope.

## Before you start

- Open the Dosya mobile app and device settings in the current released client.
- Confirm the active account and workspace, then identify mobile feature that stopped after a system update.

## Steps: recheck mobile permissions after an OS update

1. Open the Dosya mobile app and device settings and confirm the active account and workspace.
2. Locate mobile feature that stopped after a system update and verify its name or identifying details.
3. Review Dosya permissions in device settings, restore only required access, reopen the app, and retest one action.
4. Confirm that the affected feature works with an understood permission scope.

**Safety note.** Grant each operating-system permission only when its related feature is needed.

## Verify the result

After completing the steps, check the expected result: The affected feature works with an understood permission scope.

## Expected result

The controlled workflow completes and the affected feature works with an understood permission scope.

## Troubleshooting

**The expected control is missing.** Return to the Dosya mobile app and device settings, confirm the active workspace, and check that your role and client version support the action.
