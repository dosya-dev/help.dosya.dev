## Before you start

- Open the Dosya mobile file browser and search in the current released client.
- Confirm the active account and workspace, then identify known workspace and multi-level folder path.

## Steps: navigate to a deeply nested folder on mobile

1. Open the Dosya mobile file browser and search and confirm the active account and workspace.
2. Locate known workspace and multi-level folder path and verify its name or identifying details.
3. Select the workspace, open each folder level, and compare the header or breadcrumb at every step.
4. Confirm that the final file list belongs to the intended nested folder.
