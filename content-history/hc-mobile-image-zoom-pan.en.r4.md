This guide covers **Zoom and pan an image on mobile** in Dosya. The main action is to use pinch to zoom and drag to inspect a known detail; the decisive check is whether the image stays responsive and returns to fit view.

## Before you start

- Open a media file in the Dosya mobile viewer in the current released client.
- Confirm the active account and workspace, then identify high-resolution image preview.

## Steps: zoom and pan an image on mobile

1. Open a media file in the Dosya mobile viewer and confirm the active account and workspace.
2. Locate high-resolution image preview and verify its name or identifying details.
3. Use pinch to zoom and drag to inspect a known detail.
4. Confirm that the image stays responsive and returns to fit view.

**Safety note.** Large media can use substantial data and device storage; use Wi-Fi when appropriate.

## Verify the result

After completing the steps, check the expected result: The image stays responsive and returns to fit view.

## Expected result

The controlled workflow completes and the image stays responsive and returns to fit view.

## Troubleshooting

**The expected control is missing.** Return to a media file in the Dosya mobile viewer, confirm the active workspace, and check that your role and client version support the action.
