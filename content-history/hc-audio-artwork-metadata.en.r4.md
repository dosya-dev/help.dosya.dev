This guide covers **Review audio artwork and metadata** in Dosya. The main action is to open the player and compare artwork, title, artist, and album with the source tags; the decisive check is whether available embedded metadata appears correctly.

## Before you start

- Open an audio file in the Dosya player in the current released client.
- Confirm the active account and workspace, then identify audio file with embedded tags.

## Steps: review audio artwork and metadata

1. Open an audio file in the Dosya player and confirm the active account and workspace.
2. Locate audio file with embedded tags and verify its name or identifying details.
3. Open the player and compare artwork, title, artist, and album with the source tags.
4. Confirm that available embedded metadata appears correctly.

**Safety note.** Use non-sensitive media and lower device volume before testing playback controls.

## Verify the result

After completing the steps, check the expected result: Available embedded metadata appears correctly.

## Expected result

The controlled workflow completes and available embedded metadata appears correctly.

## Troubleshooting

**The expected control is missing.** Return to an audio file in the Dosya player, confirm the active workspace, and check that your role and client version support the action.
