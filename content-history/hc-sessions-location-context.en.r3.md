This guide covers **Review session location and IP context** in Dosya. The main action is to compare the approximate location and network with VPN, mobile carrier, or travel use before deciding; the decisive check is whether the location is explained or treated as suspicious.

## Before you start

- Open Profile > Security and Sessions in the current released client.
- Confirm the active account and workspace, then identify session with unexpected location information.

## Steps: review session location and IP context

1. Open Profile > Security and Sessions and confirm the active account and workspace.
2. Locate session with unexpected location information and verify its name or identifying details.
3. Compare the approximate location and network with VPN, mobile carrier, or travel use before deciding.
4. Confirm that the location is explained or treated as suspicious.

## Verify the result

After completing the steps, check the expected result: The location is explained or treated as suspicious.

## Expected result

The controlled workflow completes and the location is explained or treated as suspicious.

## Troubleshooting

**The expected control is missing.** Return to Profile > Security and Sessions, confirm the active workspace, and check that your role and client version support the action.
