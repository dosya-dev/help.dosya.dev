## Before you start

- Open Version history for a Dosya file in the current released client.
- Confirm the active account and workspace, then identify two known version rows.

## Steps: compare entries in file version history

1. Open Version history for a Dosya file and confirm the active account and workspace.
2. Locate two known version rows and verify its name or identifying details.
3. Compare timestamps, sizes, authors, and available preview or download details before choosing one.
4. Confirm that the intended revision is identified without changing the current file.
