Use this workflow to add a file to Favourites in the intended workspace.

Favourites provide a shortcut to an existing file; they do not create another stored copy or change the file location.

## Before you start

- Open Files in the current released Dosya client.
- Confirm the active account and workspace, then identify one frequently used file.

## Steps: add a file to Favourites

1. Open Files and confirm the active workspace.
2. Select one frequently used file and check its name or identifying details.
3. Choose Add to Favourites from its action menu.
4. Verify that the file appears in Favourites.

## Verify the result

Open Favourites, locate the file and confirm it opens the same object in the same workspace.

## Expected result

The workflow completes for the controlled test and the file appears in Favourites.

## Troubleshooting

**The expected control is missing.** Return to Files, confirm the active workspace and check that your role permits the action.
