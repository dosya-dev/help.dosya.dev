## Before you start

- Open a supported text file in Dosya in the current released client.
- Confirm the active account and workspace, then identify editor warning that the remote file changed.

## Steps: recover from a text edit conflict

1. Open a supported text file in Dosya and confirm the active account and workspace.
2. Locate editor warning that the remote file changed and verify its name or identifying details.
3. Copy unsaved text aside, reload the current version, then reapply and save the intended changes.
4. Confirm that the saved file includes the reviewed edit without silently replacing newer content.

**Safety note.** Keep an independent copy before making substantial edits to an important text file.

## Verify the result

After completing the steps, check the expected result: The saved file includes the reviewed edit without silently replacing newer content.

## Expected result

The controlled workflow completes and the saved file includes the reviewed edit without silently replacing newer content.

## Troubleshooting

**The expected control is missing.** Return to a supported text file in Dosya, confirm the active workspace, and check that your role and client version support the action.
