This guide covers **Download a previous file version** in Dosya. The main action is to choose Download for that revision, save it separately, and compare its details with the history row; the decisive check is whether the local copy contains the selected earlier revision.

## Before you start

- Open Version history for a Dosya file in the current released client.
- Confirm the active account and workspace, then identify previous version selected in history.

## Steps: download a previous file version

1. Open Version history for a Dosya file and confirm the active account and workspace.
2. Locate previous version selected in history and verify its name or identifying details.
3. Choose Download for that revision, save it separately, and compare its details with the history row.
4. Confirm that the local copy contains the selected earlier revision.

## Verify the result

After completing the steps, check the expected result: The local copy contains the selected earlier revision.

## Expected result

The controlled workflow completes and the local copy contains the selected earlier revision.

## Troubleshooting

**The expected control is missing.** Return to Version history for a Dosya file, confirm the active workspace, and check that your role and client version support the action.
