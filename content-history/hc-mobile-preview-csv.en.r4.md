## Before you start

- Open a file in the Dosya mobile app in the current released client.
- Confirm the active account and workspace, then identify CSV file with known columns.

## Steps: view CSV data on mobile

1. Open a file in the Dosya mobile app and confirm the active account and workspace.
2. Locate CSV file with known columns and verify its name or identifying details.
3. Open it, scroll the table, and compare a sample row with the source.
4. Confirm that the mobile table preserves the expected columns and values.
