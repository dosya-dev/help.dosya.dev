This guide covers **Clear a selection after a batch action** in Dosya. The main action is to use Clear selection or leave selection mode, then verify the batch toolbar and highlights disappear; the decisive check is whether a later action cannot accidentally reuse the old selection.

## Before you start

- Open a Dosya file or search-results list in the current released client.
- Confirm the active account and workspace, then identify completed or cancelled batch action with rows still highlighted.

## Steps: clear a selection after a batch action

1. Open a Dosya file or search-results list and confirm the active account and workspace.
2. Locate completed or cancelled batch action with rows still highlighted and verify its name or identifying details.
3. Use Clear selection or leave selection mode, then verify the batch toolbar and highlights disappear.
4. Confirm that a later action cannot accidentally reuse the old selection.

**Safety note.** Review the selection count and every selected row before starting a batch action.

## Verify the result

After completing the steps, check the expected result: A later action cannot accidentally reuse the old selection.

## Expected result

The controlled workflow completes and a later action cannot accidentally reuse the old selection.

## Troubleshooting

**The expected control is missing.** Return to a Dosya file or search-results list, confirm the active workspace, and check that your role and client version support the action.
