This guide covers **Open a WordPress site backup folder** in Dosya. The main action is to choose Open folder and inspect the stored backup items; the decisive check is whether dosya opens the folder belonging to that site.

## Before you start

- Open WordPress wp-admin and Integrations > WordPress and locate the connected site with an available root folder.
- Confirm the active account and workspace, then identify connected site with an available root folder.

## Steps: open a WordPress site backup folder

1. Confirm the account and workspace in WordPress wp-admin and Integrations > WordPress when reviewing the connected site with an available root folder.
2. Locate connected site with an available root folder and verify its name or identifying details.
3. Choose Open folder and inspect the stored backup items.
4. Confirm that Dosya opens the folder belonging to that site.

## Verify the result

After completing the steps, check the expected result: Dosya opens the folder belonging to that site.

## Expected result

The controlled workflow completes and Dosya opens the folder belonging to that site.

## Troubleshooting

**The expected control is missing.** If the required control is missing for the connected site with an available root folder, check the active workspace, your role and the client version.
