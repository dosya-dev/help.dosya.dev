This guide covers **Add folder access for a workspace member** in Dosya. The main action is to open folder access, select the precise folder, save, and test both an allowed and unrelated path; the decisive check is whether the member reaches only the intended folder scope.

## Before you start

- Open Workspace settings > Team in the current released client.
- Confirm the active account and workspace, then identify member who needs one restricted folder.

## Steps: add folder access for a workspace member

1. Open Workspace settings > Team and confirm the active account and workspace.
2. Locate member who needs one restricted folder and verify its name or identifying details.
3. Open folder access, select the precise folder, save, and test both an allowed and unrelated path.
4. Confirm that the member reaches only the intended folder scope.

**Safety note.** Use a separate test member to verify access after every role or membership change.

## Verify the result

After completing the steps, check the expected result: The member reaches only the intended folder scope.

## Expected result

The controlled workflow completes and the member reaches only the intended folder scope.

## Troubleshooting

**The expected control is missing.** Return to Workspace settings > Team, confirm the active workspace, and check that your role and client version support the action.
