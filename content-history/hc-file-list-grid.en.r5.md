Use this workflow to switch between grid and list views in the intended account or workspace.

Grid and list modes change presentation without changing the underlying folder contents. Each view may emphasize different metadata and actions.

## Before you start

- Open Files and locate the same folder in both layouts.
- Confirm the active account and workspace, then identify the same folder in both layouts.

## Steps: switch between grid and list views

1. Confirm the workspace in Files when reviewing the same folder in both layouts.
2. Select the same folder in both layouts and check its name or identifying details.
3. Switch views and compare names and actions.
4. Verify that the file set stays the same while only presentation changes.

**Safety note.** Confirm the workspace, folder scope and active filters before acting on a result.

## Verify the result

Compare the item count and several names in both views, then refresh and confirm the preferred presentation persists when supported.

## Expected result

The workflow completes for the controlled test and the file set stays the same while only presentation changes.

## Troubleshooting

**The expected control is missing.** If the required control is missing for the same folder in both layouts, check the active workspace, your role and the client version.
