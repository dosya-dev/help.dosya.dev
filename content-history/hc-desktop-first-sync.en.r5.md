Use this workflow to review a first-sync plan in the intended account or workspace.

Check the workspace, local path and sync state associated with a small local and remote test folder. Use a small local and remote test folder to distinguish device files from cloud files before a broader change.

## Before you start

- Open Desktop Sync setup in the current released Dosya client.
- Confirm the active account and workspace, then identify a small local and remote test folder.

## Steps: review a first-sync plan

1. Open Desktop Sync setup and confirm the active workspace.
2. Select a small local and remote test folder and check its name or identifying details.
3. Review the initial direction and estimated operations before enabling sync.
4. Verify that the first run matches the reviewed plan.

**Safety note.** Use a small test pair and let its current activity settle before changing advanced sync behavior.

## Verify the result

Verify that the first run matches the reviewed plan.

## Expected result

The workflow completes for the controlled test and the first run matches the reviewed plan.

## Troubleshooting

**The expected control is missing.** Return to Desktop Sync setup, confirm the active workspace and check that your role permits the action.
