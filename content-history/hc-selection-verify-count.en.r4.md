This guide covers **Verify a multi-file selection count** in Dosya. The main action is to compare the toolbar count with the highlighted rows and expand the review if the list spans views or pages; the decisive check is whether the count matches the items intended for the batch action.

## Before you start

- Open a Dosya file or search-results list in the current released client.
- Confirm the active account and workspace, then identify active selection containing known files and folders.

## Steps: verify a multi-file selection count

1. Open a Dosya file or search-results list and confirm the active account and workspace.
2. Locate active selection containing known files and folders and verify its name or identifying details.
3. Compare the toolbar count with the highlighted rows and expand the review if the list spans views or pages.
4. Confirm that the count matches the items intended for the batch action.

**Safety note.** Review the selection count and every selected row before starting a batch action.

## Verify the result

After completing the steps, check the expected result: The count matches the items intended for the batch action.

## Expected result

The controlled workflow completes and the count matches the items intended for the batch action.

## Troubleshooting

**The expected control is missing.** Return to a Dosya file or search-results list, confirm the active workspace, and check that your role and client version support the action.
