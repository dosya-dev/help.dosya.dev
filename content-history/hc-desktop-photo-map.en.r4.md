This guide covers **Open the photo map in the desktop app** in Dosya. The main action is to open Map and wait for geotagged clusters to load; the decisive check is whether mapped files appear for the active workspace.

## Before you start

- Open the Dosya desktop app and locate the Map entry in desktop navigation.
- Confirm the active account and workspace, then identify Map entry in desktop navigation.

## Steps: open the photo map in the desktop app

1. Confirm the account and workspace in the Dosya desktop app when reviewing the Map entry in desktop navigation.
2. Locate Map entry in desktop navigation and verify its name or identifying details.
3. Open Map and wait for geotagged clusters to load.
4. Confirm that mapped files appear for the active workspace.

After completing the steps, check the expected result: Mapped files appear for the active workspace.

## Expected result

The controlled workflow completes and mapped files appear for the active workspace.
