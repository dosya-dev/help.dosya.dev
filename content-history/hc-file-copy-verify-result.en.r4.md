This guide covers **Verify a copied file independently** in Dosya. The main action is to open the copy from its destination and compare name, size, preview, and file ID with the source; the decisive check is whether the copy has matching content and a separate identity.

## Before you start

- Open the Dosya file list and destination picker in the current released client.
- Confirm the active account and workspace, then identify source file and newly created copy.

## Steps: verify a copied file independently

1. Open the Dosya file list and destination picker and confirm the active account and workspace.
2. Locate source file and newly created copy and verify its name or identifying details.
3. Open the copy from its destination and compare name, size, preview, and file ID with the source.
4. Confirm that the copy has matching content and a separate identity.

**Safety note.** Use disposable samples when checking how names, permissions, and destinations behave.

## Verify the result

After completing the steps, check the expected result: The copy has matching content and a separate identity.

## Expected result

The controlled workflow completes and the copy has matching content and a separate identity.

## Troubleshooting

**The expected control is missing.** Return to the Dosya file list and destination picker, confirm the active workspace, and check that your role and client version support the action.
