This guide covers **Inspect activity event details** in Dosya. The main action is to expand the row and review outcome, source, device, resource, and available request details; the decisive check is whether the event details provide enough context to identify the operation without exposing restricted fields.

## Before you start

- Open Activity log in the current released client.
- Confirm the active account and workspace, then identify activity row for the time and resource in question.

## Steps: inspect activity event details

1. Open Activity log and confirm the active account and workspace.
2. Locate activity row for the time and resource in question and verify its name or identifying details.
3. Expand the row and review outcome, source, device, resource, and available request details.
4. Confirm that the event details provide enough context to identify the operation without exposing restricted fields.

## Verify the result

After completing the steps, check the expected result: The event details provide enough context to identify the operation without exposing restricted fields.

## Expected result

The controlled workflow completes and the event details provide enough context to identify the operation without exposing restricted fields.

## Troubleshooting

**The expected control is missing.** Return to Activity log, confirm the active workspace, and check that your role and client version support the action.
