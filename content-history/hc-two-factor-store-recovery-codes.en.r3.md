This guide covers **Store two-factor recovery codes** in Dosya. The main action is to save the codes in a protected offline or password-manager location and mark that copy with the account identity; the decisive check is whether a recovery code remains available if the authenticator device is lost.

## Before you start

- Open Account settings > Security > Two-factor authentication in the current released client.
- Confirm the active account and workspace, then identify new recovery-code set.

## Steps: store two-factor recovery codes

1. Open Account settings > Security > Two-factor authentication and confirm the active account and workspace.
2. Locate new recovery-code set and verify its name or identifying details.
3. Save the codes in a protected offline or password-manager location and mark that copy with the account identity.
4. Confirm that a recovery code remains available if the authenticator device is lost.

## Verify the result

After completing the steps, check the expected result: A recovery code remains available if the authenticator device is lost.

## Expected result

The controlled workflow completes and a recovery code remains available if the authenticator device is lost.

## Troubleshooting

**The expected control is missing.** Return to Account settings > Security > Two-factor authentication, confirm the active workspace, and check that your role and client version support the action.
