Use this workflow to show synchronized or embedded lyrics in the intended workspace.

Lyrics appear only when the audio file contains tags in a format the player supports. Playback can continue when no lyrics are available.

## Before you start

- Open Files → Audio preview in the current released Dosya client.
- Confirm the active account and workspace, then identify an audio file with embedded lyrics.

## Steps: show synchronized or embedded lyrics

1. Open Files → Audio preview and confirm the active workspace.
2. Select an audio file with embedded lyrics and check its name or identifying details.
3. Open the lyrics panel and start playback.
4. Verify that lyrics display when the file contains supported tags.

**Safety note.** Use non-confidential test media and confirm the selected filename before playback.

## Verify the result

Start playback, open the lyrics panel and confirm the displayed text belongs to the selected track.

## Expected result

The workflow completes for the controlled test and lyrics display when the file contains supported tags.

## Troubleshooting

**The expected control is missing.** Return to Files → Audio preview, confirm the active workspace and check that your role permits the action.
