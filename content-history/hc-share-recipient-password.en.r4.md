This guide covers **Enter a sharing-link password safely** in Dosya. The main action is to obtain the password through the sender agreed channel, enter it without surrounding spaces, and continue; the decisive check is whether the correct password unlocks the shared content.

## Before you start

- Open a Dosya sharing-link recipient page in the current released client.
- Confirm the active account and workspace, then identify password prompt for the intended share.

## Steps: enter a sharing-link password safely

1. Open a Dosya sharing-link recipient page and confirm the active account and workspace.
2. Locate password prompt for the intended share and verify its name or identifying details.
3. Obtain the password through the sender agreed channel, enter it without surrounding spaces, and continue.
4. Confirm that the correct password unlocks the shared content.

**Safety note.** Recipients should use the exact current link and receive passwords through a separate channel.

## Verify the result

After completing the steps, check the expected result: The correct password unlocks the shared content.

## Expected result

The controlled workflow completes and the correct password unlocks the shared content.

## Troubleshooting

**The expected control is missing.** Return to a Dosya sharing-link recipient page, confirm the active workspace, and check that your role and client version support the action.
