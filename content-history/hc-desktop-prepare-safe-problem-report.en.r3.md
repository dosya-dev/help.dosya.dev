This guide covers **Prepare a safe desktop problem report** in Dosya. The main action is to describe expected and actual behavior, include minimal steps and redacted error details, review attachments, and remove secrets; the decisive check is whether the report contains actionable evidence without private credentials or unnecessary content.

## Before you start

- Open Dosya desktop Activity, Issues, and Help views in the current released client.
- Confirm the active account and workspace, then identify problem-report form and gathered evidence.

## Steps: prepare a safe desktop problem report

1. Open Dosya desktop Activity, Issues, and Help views and confirm the active account and workspace.
2. Locate problem-report form and gathered evidence and verify its name or identifying details.
3. Describe expected and actual behavior, include minimal steps and redacted error details, review attachments, and remove secrets.
4. Confirm that the report contains actionable evidence without private credentials or unnecessary content.

## Verify the result

After completing the steps, check the expected result: The report contains actionable evidence without private credentials or unnecessary content.

## Expected result

The controlled workflow completes and the report contains actionable evidence without private credentials or unnecessary content.

## Troubleshooting

**The expected control is missing.** Return to Dosya desktop Activity, Issues, and Help views, confirm the active workspace, and check that your role and client version support the action.
