This guide covers **Install the Dosya WordPress backup plug-in** in Dosya. The main action is to in wp-admin open Plugins > Add New > Upload Plugin, select the zip, install, and activate it; the decisive check is whether the Dosya backup plug-in appears active.

## Before you start

- Open WordPress wp-admin and Integrations > WordPress and locate the downloaded dosya-backup.zip.
- Confirm the active account and workspace, then identify downloaded dosya-backup.zip.

## Steps: install the Dosya WordPress backup plug-in

1. Confirm the account and workspace in WordPress wp-admin and Integrations > WordPress when reviewing the downloaded dosya-backup.zip.
2. Locate downloaded dosya-backup.zip and verify its name or identifying details.
3. In wp-admin open Plugins > Add New > Upload Plugin, select the zip, install, and activate it.
4. Confirm that the Dosya backup plug-in appears active.

**Safety note.** Install the plug-in only from the official Dosya download and connect it through wp-admin.

## Verify the result

After completing the steps, check the expected result: The Dosya backup plug-in appears active.

## Expected result

The controlled workflow completes and the Dosya backup plug-in appears active.

## Troubleshooting

**The expected control is missing.** If the required control is missing for the downloaded dosya-backup.zip, check the active workspace, your role and the client version.
