This guide covers **Search from the correct mobile scope** in Dosya. The main action is to confirm the current scope, enter a distinctive name, and inspect folder context in each result; the decisive check is whether the search result identifies the file in its intended location.

## Before you start

- Open the Dosya mobile file browser and search in the current released client.
- Confirm the active account and workspace, then identify known file and its expected workspace or folder.

## Steps: search from the correct mobile scope

1. Open the Dosya mobile file browser and search and confirm the active account and workspace.
2. Locate known file and its expected workspace or folder and verify its name or identifying details.
3. Confirm the current scope, enter a distinctive name, and inspect folder context in each result.
4. Confirm that the search result identifies the file in its intended location.

**Safety note.** Confirm the workspace and folder breadcrumb before acting on a mobile search result.

## Verify the result

After completing the steps, check the expected result: The search result identifies the file in its intended location.

## Expected result

The controlled workflow completes and the search result identifies the file in its intended location.

## Troubleshooting

**The expected control is missing.** Return to the Dosya mobile file browser and search, confirm the active workspace, and check that your role and client version support the action.
