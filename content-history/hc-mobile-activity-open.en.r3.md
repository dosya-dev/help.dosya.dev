This guide covers **Open workspace activity on mobile** in Dosya. The main action is to open Activity and let the newest permitted events load; the decisive check is whether workspace events appear with actor, action, resource, and time.

## Before you start

- Open the Dosya mobile app in the current released client.
- Confirm the active account and workspace, then identify Activity screen for the active workspace.

## Steps: open workspace activity on mobile

1. Open the Dosya mobile app and confirm the active account and workspace.
2. Locate Activity screen for the active workspace and verify its name or identifying details.
3. Open Activity and let the newest permitted events load.
4. Confirm that workspace events appear with actor, action, resource, and time.

## Verify the result

After completing the steps, check the expected result: Workspace events appear with actor, action, resource, and time.

## Expected result

The controlled workflow completes and workspace events appear with actor, action, resource, and time.

## Troubleshooting

**The expected control is missing.** Return to the Dosya mobile app, confirm the active workspace, and check that your role and client version support the action.
