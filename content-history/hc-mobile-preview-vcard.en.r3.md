## Before you start

- Open a file in the Dosya mobile app in the current released client.
- Confirm the active account and workspace, then identify VCF file in the mobile library.

## Steps: open a vCard on mobile

1. Open a file in the Dosya mobile app and confirm the active account and workspace.
2. Locate VCF file in the mobile library and verify its name or identifying details.
3. Open it and review the parsed contact fields before choosing any device action.
4. Confirm that the contact details are readable without an automatic import.

After completing the steps, check the expected result: The contact details are readable without an automatic import.

## Expected result

## Troubleshooting
