This guide covers **Preview a vCard in the desktop app** in Dosya. The main action is to open it and review the parsed contact fields; the decisive check is whether the contact data is readable before use elsewhere.

## Before you start

- Open the Dosya desktop app and locate the VCF file in the desktop library.
- Confirm the active account and workspace, then identify VCF file in the desktop library.

## Steps: preview a vCard in the desktop app

1. Confirm the account and workspace in the Dosya desktop app when reviewing the VCF file in the desktop library.
2. Locate VCF file in the desktop library and verify its name or identifying details.
3. Open it and review the parsed contact fields.
4. Confirm that the contact data is readable before use elsewhere.

**Safety note.** Open untrusted archives or documents only after checking their source and filename.

## Verify the result

After completing the steps, check the expected result: The contact data is readable before use elsewhere.

## Expected result

The controlled workflow completes and the contact data is readable before use elsewhere.

## Troubleshooting

**The expected control is missing.** If the required control is missing for the VCF file in the desktop library, check the active workspace, your role and the client version.
