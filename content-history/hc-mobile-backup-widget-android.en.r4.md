This guide covers **Add the Dosya backup widget on Android** in Dosya. The main action is to find Dosya, add a backup-status widget, and allow it to refresh; the decisive check is whether the widget shows current backup and storage status.

## Before you start

- Open Dosya mobile backup in the current released client.
- Confirm the active account and workspace, then identify Android home-screen widget picker.

## Steps: add the Dosya backup widget on Android

1. Open Dosya mobile backup and confirm the active account and workspace.
2. Locate Android home-screen widget picker and verify its name or identifying details.
3. Find Dosya, add a backup-status widget, and allow it to refresh.
4. Confirm that the widget shows current backup and storage status.

**Safety note.** The operating system can delay background work; keep photo and background permissions enabled.

## Verify the result

After completing the steps, check the expected result: The widget shows current backup and storage status.

## Expected result

The controlled workflow completes and the widget shows current backup and storage status.

## Troubleshooting

**The expected control is missing.** Return to Dosya mobile backup, confirm the active workspace, and check that your role and client version support the action.
