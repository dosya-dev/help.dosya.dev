Use this workflow to add a folder to Favourites in the intended workspace.

A favourite points to the existing folder and does not duplicate its contents or change member access.

## Before you start

- Open Files and locate one frequently used folder.
- Confirm the active account and workspace, then identify one frequently used folder.

## Steps: add a folder to Favourites

1. Confirm the workspace in Files when reviewing one frequently used folder.
2. Select one frequently used folder and check its name or identifying details.
3. Choose Add to Favourites and open the Favourites view.
4. Verify that the folder shortcut opens the same workspace location.

**Safety note.** Use Favourites and groups as views; removing an item from them does not delete the file.

## Verify the result

Open Favourites, enter the folder and confirm its breadcrumb still shows the original workspace location.

## Expected result

The workflow completes for the controlled test and the folder shortcut opens the same workspace location.

## Troubleshooting

**The expected control is missing.** If the required control is missing for one frequently used folder, check the active workspace, your role and the client version.
