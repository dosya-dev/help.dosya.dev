Use this workflow to share several files with one link in the intended account or workspace.

A bundle link exposes the selected set under one access policy. Review every included item because one unintended file changes the whole delivery.

## Before you start

- Open Files → Share in the current released Dosya client.
- Confirm the active account and workspace, then identify a small multi-file selection.

## Steps: share several files with one link

1. Open Files → Share and confirm the active workspace.
2. Select a small multi-file selection and check its name or identifying details.
3. Create one bundle link and review included items.
4. Verify that the recipient page contains only the selected files.

## Verify the result

Open the recipient page while signed out and compare its file names and count with the reviewed selection.

## Expected result

The workflow completes for the controlled test and the recipient page contains only the selected files.

## Troubleshooting

**The expected control is missing.** Return to Files → Share, confirm the active workspace and check that your role permits the action.
