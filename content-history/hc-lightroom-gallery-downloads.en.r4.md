This guide covers **Control full-resolution downloads from a Lightroom gallery** in Dosya. The main action is to choose full downloads or view only and save; the decisive check is whether the client gallery exposes only the chosen download behavior.

## Before you start

- Open Lightroom Classic > Edit Gallery in the current released client.
- Confirm the active account and workspace, then identify download option in Edit Gallery.

## Steps: control full-resolution downloads from a Lightroom gallery

1. Open Lightroom Classic > Edit Gallery and confirm the active account and workspace.
2. Locate download option in Edit Gallery and verify its name or identifying details.
3. Choose full downloads or view only and save.
4. Confirm that the client gallery exposes only the chosen download behavior.

**Safety note.** Test access controls in a private gallery before sharing its link with a client.

## Verify the result

After completing the steps, check the expected result: The client gallery exposes only the chosen download behavior.

## Expected result

The controlled workflow completes and the client gallery exposes only the chosen download behavior.

## Troubleshooting

**The expected control is missing.** Return to Lightroom Classic > Edit Gallery, confirm the active workspace, and check that your role and client version support the action.
