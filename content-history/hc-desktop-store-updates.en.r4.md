Use this workflow to install an update from an app store in the intended account or workspace.

The main checks are the active workspace, local path and desktop sync state. Use a small local test and distinguish the device copy from the cloud copy before approving a broader change.

## Before you start

- Open Desktop Settings → Updates in the current released Dosya client.
- Confirm the active account and workspace, then identify a store-managed desktop installation.

## Steps: install an update from an app store

1. Open Desktop Settings → Updates and confirm the active workspace.
2. Select a store-managed desktop installation and check its name or identifying details.
3. Open the store update page and use the store workflow.
4. Verify that the installed version changes through the store.

## Verify the result

Verify that the installed version changes through the store.

## Expected result

The workflow completes for the controlled test and the installed version changes through the store.

## Troubleshooting

**The expected control is missing.** Return to Desktop Settings → Updates, confirm the active workspace and check that your role permits the action.
