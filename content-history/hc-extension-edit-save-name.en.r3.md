This guide covers **Rename an item before saving from the browser** in Dosya. The main action is to replace the generated name with a clear name while preserving a useful file extension; the decisive check is whether the saved item is easy to identify in Dosya.

Keep the browser profile, signed-in account, site permission, destination workspace, and folder in view while you work.

## Before you start

- Open the Save to Dosya browser extension in the current released client.
- Confirm the active account and workspace, then identify extension title or filename field.

## Steps: rename an item before saving from the browser

1. Open the Save to Dosya browser extension and confirm the active account and workspace.
2. Locate extension title or filename field and verify its name or identifying details.
3. Replace the generated name with a clear name while preserving a useful file extension.
4. Confirm that the saved item is easy to identify in Dosya.

## Verify the result

After completing the steps, check the expected result: The saved item is easy to identify in Dosya.

Open the saved result in Dosya and compare it with the selected page, screenshot, or file. Check the active browser profile, site permission, extension session, destination access, and the visible extension error.

## Expected result

The controlled workflow completes and the saved item is easy to identify in Dosya.

## Troubleshooting

**The expected control is missing.** Return to the Save to Dosya browser extension, confirm the active workspace, and check that your role and client version support the action.
