This guide covers **Revoke every other active session** in Dosya. The main action is to choose the revoke-other-sessions control, read the effect, confirm once, and refresh the list; the decisive check is whether only the intended current session remains active.

## Before you start

- Open Account settings > Security > Active sessions in the current released client.
- Confirm the active account and workspace, then identify reviewed session list with the current device identified.

## Steps: revoke every other active session

1. Open Account settings > Security > Active sessions and confirm the active account and workspace.
2. Locate reviewed session list with the current device identified and verify its name or identifying details.
3. Choose the revoke-other-sessions control, read the effect, confirm once, and refresh the list.
4. Confirm that only the intended current session remains active.

**Safety note.** Compare device, browser, time, and location context before revoking a session.

## Verify the result

After completing the steps, check the expected result: Only the intended current session remains active.

## Expected result

The controlled workflow completes and only the intended current session remains active.

## Troubleshooting

**The expected control is missing.** Return to Account settings > Security > Active sessions, confirm the active workspace, and check that your role and client version support the action.
