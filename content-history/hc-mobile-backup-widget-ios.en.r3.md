This guide covers **Add the Dosya backup widget on iPhone** in Dosya. The main action is to find Dosya, choose the backup-status size, and add it; the decisive check is whether the widget displays the signed-in account’s recent backup status.

## Before you start

- Open Dosya mobile backup in the current released client.
- Confirm the active account and workspace, then identify iOS Home Screen widget gallery.

## Steps: add the Dosya backup widget on iPhone

1. Open Dosya mobile backup and confirm the active account and workspace.
2. Locate iOS Home Screen widget gallery and verify its name or identifying details.
3. Find Dosya, choose the backup-status size, and add it.
4. Confirm that the widget displays the signed-in account’s recent backup status.

## Verify the result

After completing the steps, check the expected result: The widget displays the signed-in account’s recent backup status.

## Expected result

The controlled workflow completes and the widget displays the signed-in account’s recent backup status.

## Troubleshooting

**The expected control is missing.** Return to Dosya mobile backup, confirm the active workspace, and check that your role and client version support the action.
