This guide covers **Save a mobile file to a chosen device folder** in Dosya. The main action is to choose Save to device, select the exact local folder, and wait for completion; the decisive check is whether the file appears only in the chosen device location.

## Before you start

- Open the Dosya mobile file browser in the current released client.
- Confirm the active account and workspace, then identify file approved for local storage and the device file picker.

## Steps: save a mobile file to a chosen device folder

1. Open the Dosya mobile file browser and confirm the active account and workspace.
2. Locate file approved for local storage and the device file picker and verify its name or identifying details.
3. Choose Save to device, select the exact local folder, and wait for completion.
4. Confirm that the file appears only in the chosen device location.

**Safety note.** Confirm the active account and workspace before saving local copies or sharing content.

## Verify the result

After completing the steps, check the expected result: The file appears only in the chosen device location.

## Expected result

The controlled workflow completes and the file appears only in the chosen device location.

## Troubleshooting

**The expected control is missing.** Return to the Dosya mobile file browser, confirm the active workspace, and check that your role and client version support the action.
