This guide covers **Troubleshoot missing audio lyrics** in Dosya. The main action is to check embedded or synchronized lyric metadata and reload the track; the decisive check is whether lyrics display when supported metadata exists or the missing source data is confirmed.

## Before you start

- Open an audio file in the Dosya player in the current released client.
- Confirm the active account and workspace, then identify Lyrics panel for a track expected to contain lyrics.

## Steps: troubleshoot missing audio lyrics

1. Open an audio file in the Dosya player and confirm the active account and workspace.
2. Locate Lyrics panel for a track expected to contain lyrics and verify its name or identifying details.
3. Check embedded or synchronized lyric metadata and reload the track.
4. Confirm that lyrics display when supported metadata exists or the missing source data is confirmed.

After completing the steps, check the expected result: Lyrics display when supported metadata exists or the missing source data is confirmed.

## Expected result

The controlled workflow completes and lyrics display when supported metadata exists or the missing source data is confirmed.

## Troubleshooting

**The expected control is missing.** Return to an audio file in the Dosya player, confirm the active workspace, and check that your role and client version support the action.
