## Steps: search for an exact file name

1. Open the Dosya file search and confirm the active account and workspace.
2. Locate known complete file name including its extension and verify its name or identifying details.
3. Enter the full name, review matching rows, and compare folder and file details before opening one.
4. Confirm that the intended file is identified among exact or near-exact matches.
