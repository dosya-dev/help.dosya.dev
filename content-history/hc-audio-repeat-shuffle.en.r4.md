This guide covers **Choose repeat and shuffle modes** in Dosya. The main action is to cycle to the intended repeat or shuffle state and start the queue; the decisive check is whether the queue advances according to the displayed mode.

## Before you start

- Open an audio file in the Dosya player in the current released client.
- Confirm the active account and workspace, then identify queue playback-mode controls.

## Steps: choose repeat and shuffle modes

1. Open an audio file in the Dosya player and confirm the active account and workspace.
2. Locate queue playback-mode controls and verify its name or identifying details.
3. Cycle to the intended repeat or shuffle state and start the queue.
4. Confirm that the queue advances according to the displayed mode.

**Safety note.** Use non-sensitive media and lower device volume before testing playback controls.

## Verify the result

After completing the steps, check the expected result: The queue advances according to the displayed mode.

## Expected result

The controlled workflow completes and the queue advances according to the displayed mode.

## Troubleshooting

**The expected control is missing.** Return to an audio file in the Dosya player, confirm the active workspace, and check that your role and client version support the action.
