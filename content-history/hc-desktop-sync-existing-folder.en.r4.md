This guide covers **Sync an existing local folder safely** in Dosya. The main action is to back up critical local data, create the pair, review first-sync actions, and let a small sample complete; the decisive check is whether the existing folder begins syncing without unexpected replacement.

## Before you start

- Open Sync settings in the Dosya desktop app in the current released client.
- Confirm the active account and workspace, then identify existing local folder and empty or known remote destination.

## Steps: sync an existing local folder safely

1. Open Sync settings in the Dosya desktop app and confirm the active account and workspace.
2. Locate existing local folder and empty or known remote destination and verify its name or identifying details.
3. Back up critical local data, create the pair, review first-sync actions, and let a small sample complete.
4. Confirm that the existing folder begins syncing without unexpected replacement.

**Safety note.** Plan the first sync with a small folder and enough local and workspace storage.

## Verify the result

After completing the steps, check the expected result: The existing folder begins syncing without unexpected replacement.

## Expected result

The controlled workflow completes and the existing folder begins syncing without unexpected replacement.

## Troubleshooting

**The expected control is missing.** Return to Sync settings in the Dosya desktop app, confirm the active workspace, and check that your role and client version support the action.
