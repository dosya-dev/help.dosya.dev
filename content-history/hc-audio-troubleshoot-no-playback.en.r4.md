This guide covers **Troubleshoot audio that will not start** in Dosya. The main action is to verify upload completion, network access, volume and output device, then reopen the file and try one known-good track; the decisive check is whether the problem is isolated to the file, device output, or current connection.

## Before you start

- Open the Dosya audio player in the current released client.
- Confirm the active account and workspace, then identify known supported audio file that does not begin playing.

## Steps: troubleshoot audio that will not start

1. Open the Dosya audio player and confirm the active account and workspace.
2. Locate known supported audio file that does not begin playing and verify its name or identifying details.
3. Verify upload completion, network access, volume and output device, then reopen the file and try one known-good track.
4. Confirm that the problem is isolated to the file, device output, or current connection.

**Safety note.** Use one known playable audio file to separate source, network, metadata, and queue problems.

## Verify the result

After completing the steps, check the expected result: The problem is isolated to the file, device output, or current connection.

## Expected result

The controlled workflow completes and the problem is isolated to the file, device output, or current connection.
