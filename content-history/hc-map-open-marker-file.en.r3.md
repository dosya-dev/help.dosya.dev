This guide covers **Open a file from its map marker** in Dosya. The main action is to select the marker, verify its thumbnail or name, and open the file; the decisive check is whether dosya opens the intended file preview.

## Before you start

- Open Map in the current released client.
- Confirm the active account and workspace, then identify marker at the location you want to inspect.

## Steps: open a file from its map marker

1. Open Map and confirm the active account and workspace.
2. Locate marker at the location you want to inspect and verify its name or identifying details.
3. Select the marker, verify its thumbnail or name, and open the file.
4. Confirm that Dosya opens the intended file preview.

After completing the steps, check the expected result: Dosya opens the intended file preview.

## Expected result

## Troubleshooting
