This guide covers **Open a Dosya gallery from Lightroom** in Dosya. The main action is to run Open dosya gallery from Plug-in Extras; the decisive check is whether the browser opens the matching live gallery.

## Before you start

- Open a published collection in Lightroom Classic in the current released client.
- Confirm the active account and workspace, then identify published collection whose gallery you need to review.

## Steps: open a Dosya gallery from Lightroom

1. Open a published collection in Lightroom Classic and confirm the active account and workspace.
2. Locate published collection whose gallery you need to review and verify its name or identifying details.
3. Run Open dosya gallery from Plug-in Extras.
4. Confirm that the browser opens the matching live gallery.

## Verify the result

After completing the steps, check the expected result: The browser opens the matching live gallery.

## Expected result

The controlled workflow completes and the browser opens the matching live gallery.

## Troubleshooting

**The expected control is missing.** Return to a published collection in Lightroom Classic, confirm the active workspace, and check that your role and client version support the action.
