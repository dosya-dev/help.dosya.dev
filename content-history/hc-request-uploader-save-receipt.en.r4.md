This guide covers **Save a file-request submission receipt** in Dosya. The main action is to record the request title, submitted file names, completion time, and nonsecret receipt detail; the decisive check is whether the uploader can prove which files were accepted.

## Before you start

- Open a Dosya file-request recipient page in the current released client.
- Confirm the active account and workspace, then identify completed submission confirmation.

## Steps: save a file-request submission receipt

1. Open a Dosya file-request recipient page and confirm the active account and workspace.
2. Locate completed submission confirmation and verify its name or identifying details.
3. Record the request title, submitted file names, completion time, and nonsecret receipt detail.
4. Confirm that the uploader can prove which files were accepted.

**Safety note.** Uploaders should confirm the request owner and limits before selecting files.

## Verify the result

After completing the steps, check the expected result: The uploader can prove which files were accepted.

## Expected result

The controlled workflow completes and the uploader can prove which files were accepted.

## Troubleshooting

**The expected control is missing.** Return to a Dosya file-request recipient page, confirm the active workspace, and check that your role and client version support the action.
