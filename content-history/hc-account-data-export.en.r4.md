Use this workflow to request an export of your account data in the intended account or workspace.

The main checks are the signed-in account, current setting and expected result. Record the current state first and keep recovery, payment and identity secrets out of screenshots.

## Before you start

- Open Profile → Privacy in the current released Dosya client.
- Confirm the active account and workspace, then identify the current account.

## Steps: request an export of your account data

1. Open Profile → Privacy and confirm the active workspace.
2. Select the current account and check its name or identifying details.
3. Start the export request and confirm the delivery address.
4. Verify that the request shows as pending or provides a completed export.

## Verify the result

Verify that the request shows as pending or provides a completed export.

## Expected result

The workflow completes for the controlled test and the request shows as pending or provides a completed export.

## Troubleshooting

**The expected control is missing.** Return to Profile → Privacy, confirm the active workspace and check that your role permits the action.
