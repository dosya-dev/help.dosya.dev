This guide covers **Set a folder password safely** in Dosya. The main action is to use a unique strong password, store it in an approved manager, save the setting, and test access in a separate session; the decisive check is whether the folder requires the new password without exposing it in messages or screenshots.

## Before you start

- Open a Dosya folder and its access or lock settings in the current released client.
- Confirm the active account and workspace, then identify folder that supports password protection.

## Steps: set a folder password safely

1. Open a Dosya folder and its access or lock settings and confirm the active account and workspace.
2. Locate folder that supports password protection and verify its name or identifying details.
3. Use a unique strong password, store it in an approved manager, save the setting, and test access in a separate session.
4. Confirm that the folder requires the new password without exposing it in messages or screenshots.

**Safety note.** Test protection with a separate member before relying on it for important content.

## Verify the result

After completing the steps, check the expected result: The folder requires the new password without exposing it in messages or screenshots.

## Expected result

The controlled workflow completes and the folder requires the new password without exposing it in messages or screenshots.

## Troubleshooting

**The expected control is missing.** Return to a Dosya folder and its access or lock settings, confirm the active workspace, and check that your role and client version support the action.
