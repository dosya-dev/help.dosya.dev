This guide covers **Identify the current Dosya session** in Dosya. The main action is to compare its browser or app, operating system, last-active time, and approximate location with the device in hand; the decisive check is whether the current session is distinguished from other signed-in devices.

## Before you start

- Open Account settings > Security > Active sessions in the current released client.
- Confirm the active account and workspace, then identify session marked as the current device.

## Steps: identify the current Dosya session

1. Open Account settings > Security > Active sessions and confirm the active account and workspace.
2. Locate session marked as the current device and verify its name or identifying details.
3. Compare its browser or app, operating system, last-active time, and approximate location with the device in hand.
4. Confirm that the current session is distinguished from other signed-in devices.

**Safety note.** Compare device, browser, time, and location context before revoking a session.

## Verify the result

After completing the steps, check the expected result: The current session is distinguished from other signed-in devices.

## Expected result

The controlled workflow completes and the current session is distinguished from other signed-in devices.

## Troubleshooting

**The expected control is missing.** Return to Account settings > Security > Active sessions, confirm the active workspace, and check that your role and client version support the action.
