This guide covers **Find text in a desktop file preview** in Dosya. The main action is to open Find, enter the search text, and move between matches; the decisive check is whether each matching occurrence is highlighted in order.

## Before you start

- Open the Dosya desktop app and locate the open supported text preview.
- Confirm the active account and workspace, then identify open supported text preview.

## Steps: find text in a desktop file preview

1. Confirm the account and workspace in the Dosya desktop app when reviewing the open supported text preview.
2. Locate open supported text preview and verify its name or identifying details.
3. Open Find, enter the search text, and move between matches.
4. Confirm that each matching occurrence is highlighted in order.

**Safety note.** Open untrusted archives or documents only after checking their source and filename.

## Verify the result

After completing the steps, check the expected result: Each matching occurrence is highlighted in order.

## Expected result

The controlled workflow completes and each matching occurrence is highlighted in order.

## Troubleshooting

**The expected control is missing.** If the required control is missing for the open supported text preview, check the active workspace, your role and the client version.
