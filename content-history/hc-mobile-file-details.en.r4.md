This guide covers **Review mobile file details and actions** in Dosya. The main action is to open Details or More and inspect type, size, dates, location, and available actions; the decisive check is whether the metadata and controls match the selected file.

## Before you start

- Open the Dosya mobile app and locate the file in the mobile viewer.
- Confirm the active account and workspace, then identify file in the mobile viewer.

## Steps: review mobile file details and actions

1. Confirm the account and workspace in the Dosya mobile app when reviewing the file in the mobile viewer.
2. Locate file in the mobile viewer and verify its name or identifying details.
3. Open Details or More and inspect type, size, dates, location, and available actions.
4. Confirm that the metadata and controls match the selected file.

**Safety note.** Confirm the active workspace and selected file before using mobile actions.

## Verify the result

After completing the steps, check the expected result: The metadata and controls match the selected file.

## Expected result

The controlled workflow completes and the metadata and controls match the selected file.

## Troubleshooting

**The expected control is missing.** If the required control is missing for the file in the mobile viewer, check the active workspace, your role and the client version.
