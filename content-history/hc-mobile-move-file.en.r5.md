Use this workflow to move a file on mobile in the intended workspace.

Moving changes the file folder inside the active workspace. It does not download the file to the phone or move it between workspaces.

## Before you start

- Open Mobile Files in the current released Dosya client.
- Confirm the active account and workspace, then identify one test file.

## Steps: move a file on mobile

1. Open Mobile Files and confirm the active workspace.
2. Select one test file and check its name or identifying details.
3. Choose Move, browse to the destination and confirm.
4. Verify that the file appears once in the destination folder.

**Safety note.** Use the current released mobile app and confirm its active workspace before changing files.

## Verify the result

Open the destination folder after refresh and confirm the file is present once and absent from its former folder.

## Expected result

The workflow completes for the controlled test and the file appears once in the destination folder.

## Troubleshooting

**The expected control is missing.** Return to Mobile Files, confirm the active workspace and check that your role permits the action.
