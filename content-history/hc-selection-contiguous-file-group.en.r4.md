This guide covers **Select a contiguous group of files** in Dosya. The main action is to select the first row, use the supported range-selection gesture on the last row, and inspect the highlighted range; the decisive check is whether every row inside the intended range is selected once.

## Before you start

- Open a Dosya file or search-results list in the current released client.
- Confirm the active account and workspace, then identify adjacent disposable rows in one file list.

## Steps: select a contiguous group of files

1. Open a Dosya file or search-results list and confirm the active account and workspace.
2. Locate adjacent disposable rows in one file list and verify its name or identifying details.
3. Select the first row, use the supported range-selection gesture on the last row, and inspect the highlighted range.
4. Confirm that every row inside the intended range is selected once.

**Safety note.** Review the selection count and every selected row before starting a batch action.

## Verify the result

After completing the steps, check the expected result: Every row inside the intended range is selected once.

## Expected result

The controlled workflow completes and every row inside the intended range is selected once.

## Troubleshooting

**The expected control is missing.** Return to a Dosya file or search-results list, confirm the active workspace, and check that your role and client version support the action.
