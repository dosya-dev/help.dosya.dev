This guide covers **Save a Vault file locally from desktop** in Dosya. The main action is to choose Save or Download, select a trusted local destination, and wait for decryption; the decisive check is whether the local file opens and matches the source.

## Before you start

- Open Vault in the Dosya desktop app in the current released client.
- Confirm the active account and workspace, then identify known encrypted test file.

## Steps: save a Vault file locally from desktop

1. Open Vault in the Dosya desktop app and confirm the active account and workspace.
2. Locate known encrypted test file and verify its name or identifying details.
3. Choose Save or Download, select a trusted local destination, and wait for decryption.
4. Confirm that the local file opens and matches the source.

**Safety note.** Vault encryption happens on the device; keep the recovery key outside Dosya.

## Verify the result

After completing the steps, check the expected result: The local file opens and matches the source.

## Expected result

The controlled workflow completes and the local file opens and matches the source.

## Troubleshooting

**The expected control is missing.** Return to Vault in the Dosya desktop app, confirm the active workspace, and check that your role and client version support the action.
