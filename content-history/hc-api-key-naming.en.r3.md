This guide covers **Name an API key for its owner and purpose** in Dosya. The main action is to enter a name that identifies the app, environment, and responsible owner; the decisive check is whether the key can be recognized later without revealing its secret.

## Before you start

- Open Profile > Integrations > API keys in the current released client.
- Confirm the active account and workspace, then identify new API key name field.

## Steps: name an API key for its owner and purpose

1. Open Profile > Integrations > API keys and confirm the active account and workspace.
2. Locate new API key name field and verify its name or identifying details.
3. Enter a name that identifies the app, environment, and responsible owner.
4. Confirm that the key can be recognized later without revealing its secret.

## Verify the result

After completing the steps, check the expected result: The key can be recognized later without revealing its secret.

## Expected result

The controlled workflow completes and the key can be recognized later without revealing its secret.

## Troubleshooting

**The expected control is missing.** Return to Profile > Integrations > API keys, confirm the active workspace, and check that your role and client version support the action.
