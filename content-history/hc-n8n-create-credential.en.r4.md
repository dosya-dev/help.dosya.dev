## Before you start

- Open Zapier or n8n with Dosya in the current released client.
- Confirm the active account and workspace, then identify Dosya credential form in n8n.

## Steps: create a Dosya credential in n8n

1. Open Zapier or n8n with Dosya and confirm the active account and workspace.
2. Locate Dosya credential form in n8n and verify its name or identifying details.
3. Enter a restricted API credential, save it, and run the connection test.
4. Confirm that n8n can access only the intended Dosya scope.

## Verify the result

After completing the steps, check the expected result: N8n can access only the intended Dosya scope.

## Expected result

The controlled workflow completes and n8n can access only the intended Dosya scope.

## Troubleshooting
