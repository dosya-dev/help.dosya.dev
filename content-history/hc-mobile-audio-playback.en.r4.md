This guide covers **Play audio in the mobile viewer** in Dosya. The main action is to start playback and test seek, pause, and background behavior; the decisive check is whether the player reports the correct track and position.

## Before you start

- Open a media file in the Dosya mobile viewer in the current released client.
- Confirm the active account and workspace, then identify supported audio file.

## Steps: play audio in the mobile viewer

1. Open a media file in the Dosya mobile viewer and confirm the active account and workspace.
2. Locate supported audio file and verify its name or identifying details.
3. Start playback and test seek, pause, and background behavior.
4. Confirm that the player reports the correct track and position.

**Safety note.** Large media can use substantial data and device storage; use Wi-Fi when appropriate.

## Verify the result

After completing the steps, check the expected result: The player reports the correct track and position.

## Expected result

The controlled workflow completes and the player reports the correct track and position.

## Troubleshooting

**The expected control is missing.** Return to a media file in the Dosya mobile viewer, confirm the active workspace, and check that your role and client version support the action.
