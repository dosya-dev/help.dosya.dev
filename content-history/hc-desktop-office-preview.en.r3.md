This guide covers **Preview an Office document in the desktop app** in Dosya. The main action is to open the file and let the local desktop preview render; the decisive check is whether the document is readable in the desktop window.

## Before you start

- Open the Dosya desktop app in the current released client.
- Confirm the active account and workspace, then identify supported Office file.

## Steps: preview an Office document in the desktop app

1. Open the Dosya desktop app and confirm the active account and workspace.
2. Locate supported Office file and verify its name or identifying details.
3. Open the file and let the local desktop preview render.
4. Confirm that the document is readable in the desktop window.

## Verify the result

After completing the steps, check the expected result: The document is readable in the desktop window.

## Expected result

The controlled workflow completes and the document is readable in the desktop window.

## Troubleshooting

**The expected control is missing.** Return to the Dosya desktop app, confirm the active workspace, and check that your role and client version support the action.
