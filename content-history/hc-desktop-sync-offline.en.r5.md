Check the workspace, local path and sync state associated with a sync pair while temporarily offline. Use a sync pair while temporarily offline to distinguish device files from cloud files before a broader change.

## Before you start

- Open Desktop Sync status in the current released Dosya client.
- Confirm the active account and workspace, then identify a sync pair while temporarily offline.

## Steps: understand Offline desktop sync status

1. Open Desktop Sync status and confirm the active workspace.
2. Select a sync pair while temporarily offline and check its name or identifying details.
3. Review the Offline label, then reconnect the network.
4. Verify that the pair returns to checking or synced without recreation.

**Safety note.** Use a small test pair and let its current activity settle before changing advanced sync behavior.

## Verify the result

Verify that the pair returns to checking or synced without recreation.

## Expected result

The workflow completes for the controlled test and the pair returns to checking or synced without recreation.

## Troubleshooting

**The expected control is missing.** Return to Desktop Sync status, confirm the active workspace and check that your role permits the action.
