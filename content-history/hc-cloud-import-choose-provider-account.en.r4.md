This guide covers **Choose the correct cloud-provider account** in Dosya. The main action is to compare the provider email or organization, switch if needed, and authorize only the intended account; the decisive check is whether the connected source belongs to the expected provider account.

## Before you start

- Open Integrations > Cloud import in the current released client.
- Confirm the active account and workspace, then identify provider authorization page with the signed-in identity.

## Steps: choose the correct cloud-provider account

1. Open Integrations > Cloud import and confirm the active account and workspace.
2. Locate provider authorization page with the signed-in identity and verify its name or identifying details.
3. Compare the provider email or organization, switch if needed, and authorize only the intended account.
4. Confirm that the connected source belongs to the expected provider account.

**Safety note.** Use a disposable provider folder first and grant only the access requested by the picker.

## Verify the result

After completing the steps, check the expected result: The connected source belongs to the expected provider account.

## Expected result

The controlled workflow completes and the connected source belongs to the expected provider account.

## Troubleshooting

**The expected control is missing.** Return to Integrations > Cloud import, confirm the active workspace, and check that your role and client version support the action.
