This guide covers **Scan the authenticator QR code safely** in Dosya. The main action is to scan the code directly into a trusted authenticator, avoid recording it, and keep the setup page private; the decisive check is whether the authenticator creates a time-based code for the expected Dosya account.

## Before you start

- Open Account settings > Security > Two-factor authentication in the current released client.
- Confirm the active account and workspace, then identify new two-factor setup QR code.

## Steps: scan the authenticator QR code safely

1. Open Account settings > Security > Two-factor authentication and confirm the active account and workspace.
2. Locate new two-factor setup QR code and verify its name or identifying details.
3. Scan the code directly into a trusted authenticator, avoid recording it, and keep the setup page private.
4. Confirm that the authenticator creates a time-based code for the expected Dosya account.

**Safety note.** Finish enrollment only after a fresh authenticator code succeeds and recovery codes are stored safely.

## Verify the result

After completing the steps, check the expected result: The authenticator creates a time-based code for the expected Dosya account.

## Expected result

The controlled workflow completes and the authenticator creates a time-based code for the expected Dosya account.

## Troubleshooting

**The expected control is missing.** Return to Account settings > Security > Two-factor authentication, confirm the active workspace, and check that your role and client version support the action.
