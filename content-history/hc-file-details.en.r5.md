Use this workflow to view file details in the intended workspace.

Details identify the selected object and help distinguish similar names. Size, type, owner and timestamps can explain why two apparently identical files differ.

## Before you start

- Open Files → Details in the current released Dosya client.
- Confirm the active account and workspace, then identify the intended file.

## Steps: view file details

1. Open Files → Details and confirm the active workspace.
2. Select the intended file and check its name or identifying details.
3. Open Details and review name, type, size, owner and timestamps.
4. Verify that the details match the file you selected.

**Safety note.** Confirm the selected file and workspace before changing or copying it.

## Verify the result

Compare at least two fields besides the name, then return to the containing folder without changing the file.

## Expected result

The workflow completes for the controlled test and the details match the file you selected.

## Troubleshooting

**The expected control is missing.** Return to Files → Details, confirm the active workspace and check that your role permits the action.
