## Before you start

- Open the Dosya mobile file browser in the current released client.
- Confirm the active account and workspace, then identify mobile workspace selector and current folder.

## Steps: confirm the active workspace on mobile

1. Open the Dosya mobile file browser and confirm the active account and workspace.
2. Locate mobile workspace selector and current folder and verify its name or identifying details.
3. Compare the workspace name and breadcrumb with the expected file location before acting.
4. Confirm that subsequent mobile actions use the intended workspace.
