This guide covers **Save changes to a text file** in Dosya. The main action is to make the edit, choose Save, and wait for the completion state; the decisive check is whether the new content persists after reopening the file.

## Before you start

- Open a supported text file in Dosya in the current released client.
- Confirm the active account and workspace, then identify small controlled edit in the browser editor.

## Steps: save changes to a text file

1. Open a supported text file in Dosya and confirm the active account and workspace.
2. Locate small controlled edit in the browser editor and verify its name or identifying details.
3. Make the edit, choose Save, and wait for the completion state.
4. Confirm that the new content persists after reopening the file.

**Safety note.** Keep an independent copy before making substantial edits to an important text file.

## Verify the result

After completing the steps, check the expected result: The new content persists after reopening the file.

## Expected result

The controlled workflow completes and the new content persists after reopening the file.

## Troubleshooting

**The expected control is missing.** Return to a supported text file in Dosya, confirm the active workspace, and check that your role and client version support the action.
