Use this workflow to sort files by name, size or date in the intended workspace.

Sorting changes display order only; it does not rename, move or edit files. The selected field and direction determine which item appears first.

## Before you start

- Open Files and locate a folder with varied test files.
- Confirm the active account and workspace, then identify a folder with varied test files.

## Steps: sort files by name, size or date

1. Confirm the workspace in Files when reviewing a folder with varied test files.
2. Select a folder with varied test files and check its name or identifying details.
3. Choose a sort field and direction.
4. Verify that the first and last items follow the selected order.

**Safety note.** Confirm the workspace, folder scope and active filters before acting on a result.

## Verify the result

Compare the first and last visible items, reverse the direction once and confirm their order changes predictably.

## Expected result

The workflow completes for the controlled test and the first and last items follow the selected order.

## Troubleshooting

**The expected control is missing.** If the required control is missing for a folder with varied test files, check the active workspace, your role and the client version.
