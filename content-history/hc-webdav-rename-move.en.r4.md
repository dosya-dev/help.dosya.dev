This guide covers **Rename and move files over WebDAV** in Dosya. The main action is to rename the file, move it once, and refresh both folders; the decisive check is whether the file has one final name and location in Dosya.

## Before you start

- Open a WebDAV client connected to Dosya and locate the disposable remote file and destination folder.
- Confirm the active account and workspace, then identify disposable remote file and destination folder.

## Steps: rename and move files over WebDAV

1. Confirm the account and workspace in a WebDAV client connected to Dosya when reviewing the disposable remote file and destination folder.
2. Locate disposable remote file and destination folder and verify its name or identifying details.
3. Rename the file, move it once, and refresh both folders.
4. Confirm that the file has one final name and location in Dosya.

**Safety note.** Use a restricted WebDAV key and expect client behavior to vary by operating system.

## Verify the result

After completing the steps, check the expected result: The file has one final name and location in Dosya.

## Expected result

The controlled workflow completes and the file has one final name and location in Dosya.

## Troubleshooting

**The expected control is missing.** If the required control is missing for the disposable remote file and destination folder, check the active workspace, your role and the client version.
