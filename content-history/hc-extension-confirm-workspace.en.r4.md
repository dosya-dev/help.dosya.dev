This guide covers **Confirm the extension account and workspace** in Dosya. The main action is to compare the signed-in identity and selected workspace with the intended destination before capturing; the decisive check is whether the extension will save into the correct account context.

For the browser item in the confirmed workspace, keep the browser profile, account, site permission and destination folder visible.

## Before you start

- Open the Save to Dosya browser extension in the current released client.
- Confirm the active account and workspace, then identify extension account, workspace, and destination controls.

## Steps: confirm the extension account and workspace

1. Open the Save to Dosya browser extension and confirm the active account and workspace.
2. Locate extension account, workspace, and destination controls and verify its name or identifying details.
3. Compare the signed-in identity and selected workspace with the intended destination before capturing.
4. Confirm that the extension will save into the correct account context.

**Safety note.** Review the captured preview and destination before saving private web content.

## Verify the result

After completing the steps, check the expected result: The extension will save into the correct account context.

Compare the browser item in the confirmed workspace in Dosya with the original browser content. If the browser item in the confirmed workspace is missing or incorrect, check the browser profile, site permission, extension session and destination error.

## Expected result

The controlled workflow completes and the extension will save into the correct account context.

## Troubleshooting

**The expected control is missing.** Return to the Save to Dosya browser extension, confirm the active workspace, and check that your role and client version support the action.
