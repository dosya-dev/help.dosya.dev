This guide covers **Import one provider folder as a test** in Dosya. The main action is to select that folder, choose a disposable Dosya destination, and start the import; the decisive check is whether the provider folder arrives with its expected children.

## Before you start

- Open Integrations > Cloud import in the current released client.
- Confirm the active account and workspace, then identify small non-confidential source folder.

## Steps: import one provider folder as a test

1. Open Integrations > Cloud import and confirm the active account and workspace.
2. Locate small non-confidential source folder and verify its name or identifying details.
3. Select that folder, choose a disposable Dosya destination, and start the import.
4. Confirm that the provider folder arrives with its expected children.

**Safety note.** Use a disposable provider folder first and grant only the access requested by the picker.

## Verify the result

After completing the steps, check the expected result: The provider folder arrives with its expected children.

## Expected result

The controlled workflow completes and the provider folder arrives with its expected children.

## Troubleshooting

**The expected control is missing.** Return to Integrations > Cloud import, confirm the active workspace, and check that your role and client version support the action.
