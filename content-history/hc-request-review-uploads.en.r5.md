Use this workflow to review files submitted to a request in the intended account or workspace.

Request uploads should be reviewed by sender, filename, time and destination before they are trusted or shared. Treat unexpected files cautiously.

## Before you start

- Open File request details in the current released Dosya client.
- Confirm the active account and workspace, then identify a request with test submissions.

## Steps: review files submitted to a request

1. Open File request details and confirm the active workspace.
2. Select a request with test submissions and check its name or identifying details.
3. Open Uploads and compare sender, filename and time.
4. Verify that each expected submission is accounted for.

**Safety note.** Use a test recipient and confirm the receiving folder before sending a request.

## Verify the result

Compare the upload list with expected submissions, then preview or scan harmless examples according to your organization’s process.

## Expected result

The workflow completes for the controlled test and each expected submission is accounted for.

## Troubleshooting

**The expected control is missing.** Return to File request details, confirm the active workspace and check that your role permits the action.
