This guide covers **Switch workspaces in the desktop app** in Dosya. The main action is to select a different authorized workspace and wait for its library to load; the decisive check is whether navigation and file results belong to the selected workspace.

## Before you start

- Open the Dosya desktop app and locate the workspace switcher in the desktop navigation.
- Confirm the active account and workspace, then identify workspace switcher in the desktop navigation.

## Steps: switch workspaces in the desktop app

1. Confirm the account and workspace in the Dosya desktop app when reviewing the workspace switcher in the desktop navigation.
2. Locate workspace switcher in the desktop navigation and verify its name or identifying details.
3. Select a different authorized workspace and wait for its library to load.
4. Confirm that navigation and file results belong to the selected workspace.

**Safety note.** Keyboard commands follow the focused window and may differ by operating system.

## Verify the result

After completing the steps, check the expected result: Navigation and file results belong to the selected workspace.

## Expected result

The controlled workflow completes and navigation and file results belong to the selected workspace.

## Troubleshooting

**The expected control is missing.** If the required control is missing for the workspace switcher in the desktop navigation, check the active workspace, your role and the client version.
