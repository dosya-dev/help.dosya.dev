This guide covers **Read a PDF on mobile** in Dosya. The main action is to open it, zoom text, and move to a known page; the decisive check is whether the expected page renders legibly.

## Before you start

- Open a media file in the Dosya mobile viewer in the current released client.
- Confirm the active account and workspace, then identify multi-page PDF.

## Steps: read a PDF on mobile

1. Open a media file in the Dosya mobile viewer and confirm the active account and workspace.
2. Locate multi-page PDF and verify its name or identifying details.
3. Open it, zoom text, and move to a known page.
4. Confirm that the expected page renders legibly.

**Safety note.** Large media can use substantial data and device storage; use Wi-Fi when appropriate.

## Verify the result

After completing the steps, check the expected result: The expected page renders legibly.

## Expected result

The controlled workflow completes and the expected page renders legibly.

## Troubleshooting

**The expected control is missing.** Return to a media file in the Dosya mobile viewer, confirm the active workspace, and check that your role and client version support the action.
