This guide covers **Preview an Office document on mobile** in Dosya. The main action is to open the file and wait for the document preview stage; the decisive check is whether the document renders inside the mobile viewer.

## Before you start

- Open a file in the Dosya mobile app in the current released client.
- Confirm the active account and workspace, then identify supported Office file in the mobile library.

## Steps: preview an Office document on mobile

1. Open a file in the Dosya mobile app and confirm the active account and workspace.
2. Locate supported Office file in the mobile library and verify its name or identifying details.
3. Open the file and wait for the document preview stage.
4. Confirm that the document renders inside the mobile viewer.

**Safety note.** Large or unsupported previews may need a download and a compatible device app.

## Verify the result

After completing the steps, check the expected result: The document renders inside the mobile viewer.

## Expected result

The controlled workflow completes and the document renders inside the mobile viewer.

## Troubleshooting

**The expected control is missing.** Return to a file in the Dosya mobile app, confirm the active workspace, and check that your role and client version support the action.
