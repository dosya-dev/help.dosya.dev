Use this workflow to back up Live Photos and motion photos in the intended account or workspace.

The main checks are the mobile account, workspace and device permission. Use a non-confidential mobile test and confirm the cloud result from Files before removing device data.

## Before you start

- Open Mobile Backup settings in the current released Dosya client.
- Confirm the active account and workspace, then identify a small Live Photo or motion-photo sample.

## Steps: back up Live Photos and motion photos

1. Open Mobile Backup settings and confirm the active workspace.
2. Select a small Live Photo or motion-photo sample and check its name or identifying details.
3. Enable the supported paired-media option and start backup.
4. Verify that the cloud copy keeps the supported image and motion parts together.

## Verify the result

Verify that the cloud copy keeps the supported image and motion parts together.

## Expected result

The workflow completes for the controlled test and the cloud copy keeps the supported image and motion parts together.

## Troubleshooting

**The expected control is missing.** Return to Mobile Backup settings, confirm the active workspace and check that your role permits the action.
