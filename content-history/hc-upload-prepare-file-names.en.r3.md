This guide covers **Prepare file names before uploading** in Dosya. The main action is to remove ambiguous duplicate names, unsupported control characters, and temporary suffixes before adding the files; the decisive check is whether the selected items have stable, recognizable names.

Keep the source file, destination folder, available storage, and transfer state in view while you work.

## Before you start

- Open the Dosya upload view in the current released client.
- Confirm the active account and workspace, then identify local files selected for upload.

## Steps: prepare file names before uploading

1. Open the Dosya upload view and confirm the active account and workspace.
2. Locate local files selected for upload and verify its name or identifying details.
3. Remove ambiguous duplicate names, unsupported control characters, and temporary suffixes before adding the files.
4. Confirm that the selected items have stable, recognizable names.

## Verify the result

After completing the steps, check the expected result: The selected items have stable, recognizable names.

Compare the uploaded item’s name, size, and destination with the source before removing any local copy. Record the failed item and its exact transfer message before retrying; repeated blind retries can hide a size, quota, or destination problem.

## Expected result

The controlled workflow completes and the selected items have stable, recognizable names.

## Troubleshooting

**The expected control is missing.** Return to the Dosya upload view, confirm the active workspace, and check that your role and client version support the action.
