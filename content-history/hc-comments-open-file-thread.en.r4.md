This guide covers **Open the comment thread for a file** in Dosya. The main action is to open its preview and switch to the Comments panel; the decisive check is whether the thread shown belongs to the selected file.

## Before you start

- Open a file preview and its Comments panel in the current released client.
- Confirm the active account and workspace, then identify file whose discussion you need.

## Steps: open the comment thread for a file

1. Open a file preview and its Comments panel and confirm the active account and workspace.
2. Locate file whose discussion you need and verify its name or identifying details.
3. Open its preview and switch to the Comments panel.
4. Confirm that the thread shown belongs to the selected file.

**Safety note.** Use comments for file-specific context and avoid posting secrets or access credentials.

## Verify the result

After completing the steps, check the expected result: The thread shown belongs to the selected file.

## Expected result

The controlled workflow completes and the thread shown belongs to the selected file.

## Troubleshooting

**The expected control is missing.** Return to a file preview and its Comments panel, confirm the active workspace, and check that your role and client version support the action.
