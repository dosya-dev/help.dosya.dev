This guide covers **Choose a folder for a remote download** in Dosya. The main action is to open the picker, select the intended destination, and confirm; the decisive check is whether the chosen folder name appears before the job starts.

## Before you start

- Open Integrations > Remote Downloads in the current released client.
- Confirm the active account and workspace, then identify folder button beside the URL field.

## Steps: choose a folder for a remote download

1. Open Integrations > Remote Downloads and confirm the active account and workspace.
2. Locate folder button beside the URL field and verify its name or identifying details.
3. Open the picker, select the intended destination, and confirm.
4. Confirm that the chosen folder name appears before the job starts.

## Verify the result

After completing the steps, check the expected result: The chosen folder name appears before the job starts.

## Expected result

The controlled workflow completes and the chosen folder name appears before the job starts.

## Troubleshooting

**The expected control is missing.** Return to Integrations > Remote Downloads, confirm the active workspace, and check that your role and client version support the action.
