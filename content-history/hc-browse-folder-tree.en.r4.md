Use this workflow to browse a deep folder tree in the intended account or workspace.

The main checks are the active workspace, folder path and target item. Start with one harmless item and compare the source and destination after refreshing the view.

## Before you start

- Open Files and the folder tree in the current released Dosya client.
- Confirm the active account and workspace, then identify a nested folder path.

## Steps: browse a deep folder tree

1. Open Files and the folder tree and confirm the active workspace.
2. Select a nested folder path and check its name or identifying details.
3. Expand the tree one level at a time and open the final folder.
4. Verify that the content pane and tree selection show the same location.

## Verify the result

Verify that the content pane and tree selection show the same location.

## Expected result

The workflow completes for the controlled test and the content pane and tree selection show the same location.

## Troubleshooting

**The expected control is missing.** Return to Files and the folder tree, confirm the active workspace and check that your role permits the action.
