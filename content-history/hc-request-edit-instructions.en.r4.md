This guide covers **Edit file-request instructions** in Dosya. The main action is to update the client-facing text, save, and reopen the recipient page; the decisive check is whether the revised instructions are visible to uploaders.

## Before you start

- Open a Dosya file request in the current released client.
- Confirm the active account and workspace, then identify request title and instructions controls.

## Steps: edit file-request instructions

1. Open a Dosya file request and confirm the active account and workspace.
2. Locate request title and instructions controls and verify its name or identifying details.
3. Update the client-facing text, save, and reopen the recipient page.
4. Confirm that the revised instructions are visible to uploaders.

**Safety note.** Use a test recipient and verify the destination before changing a live request.

## Verify the result

After completing the steps, check the expected result: The revised instructions are visible to uploaders.

## Expected result

The controlled workflow completes and the revised instructions are visible to uploaders.

## Troubleshooting

**The expected control is missing.** Return to a Dosya file request, confirm the active workspace, and check that your role and client version support the action.
