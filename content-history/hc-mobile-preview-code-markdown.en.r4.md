## Before you start

- Open a file in the Dosya mobile app in the current released client.
- Confirm the active account and workspace, then identify supported code or Markdown file.

## Steps: preview source code or Markdown on mobile

1. Open a file in the Dosya mobile app and confirm the active account and workspace.
2. Locate supported code or Markdown file and verify its name or identifying details.
3. Open it and review syntax or formatted content using the viewer theme.
4. Confirm that the file is readable with the intended presentation.

## Verify the result

After completing the steps, check the expected result: The file is readable with the intended presentation.

## Expected result

The controlled workflow completes and the file is readable with the intended presentation.

## Troubleshooting
