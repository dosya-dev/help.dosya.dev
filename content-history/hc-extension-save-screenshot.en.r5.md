Use this workflow to save a browser screenshot to Dosya in the intended account or workspace.

A browser screenshot can contain private page content, account names or tokens visible on screen. Use a non-sensitive page and review the capture before saving.

## Before you start

- Open Save to Dosya extension in the current released Dosya client.
- Confirm the active account and workspace, then identify a non-sensitive test page.

## Steps: save a browser screenshot to Dosya

1. Open Save to Dosya extension and confirm the active workspace.
2. Select a non-sensitive test page and check its name or identifying details.
3. Choose Screenshot, review the capture and save.
4. Verify that a screenshot file appears in the selected folder.

<figure class="help-screenshot"><a href="/screenshots/extension-save-controls-2026-10-10-r2.webp"><img src="/screenshots/extension-save-controls-2026-10-10-r2.webp" alt="Reference for “Save a browser screenshot to Dosya”: Save to Dosya extension showing capture type and destination controls." width="360" height="560" loading="lazy" decoding="async" /></a><figcaption>Reference for “Save a browser screenshot to Dosya”: Save to Dosya extension showing capture type and destination controls. <a href="/screenshots/extension-save-controls-2026-10-10-r2.webp">Open full-size screenshot</a>.</figcaption></figure>

**Safety note.** Use a non-sensitive test page and confirm the extension destination before saving.

## Verify the result

Open the saved image in Dosya and confirm its content, filename and destination folder before sharing it.

## Expected result

The workflow completes for the controlled test and a screenshot file appears in the selected folder.

## Troubleshooting

**The expected control is missing.** Return to Save to Dosya extension, confirm the active workspace and check that your role permits the action.
