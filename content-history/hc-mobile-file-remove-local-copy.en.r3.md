This guide covers **Remove an unwanted mobile download safely** in Dosya. The main action is to confirm the cloud file still exists, delete the device copy through the operating system, and re-open the cloud item in Dosya; the decisive check is whether the local copy is removed while the Dosya file remains available.

## Before you start

- Open the Dosya mobile file browser in the current released client.
- Confirm the active account and workspace, then identify local device copy that is no longer required.

## Steps: remove an unwanted mobile download safely

1. Open the Dosya mobile file browser and confirm the active account and workspace.
2. Locate local device copy that is no longer required and verify its name or identifying details.
3. Confirm the cloud file still exists, delete the device copy through the operating system, and re-open the cloud item in Dosya.
4. Confirm that the local copy is removed while the Dosya file remains available.

After completing the steps, check the expected result: The local copy is removed while the Dosya file remains available.

## Expected result

The controlled workflow completes and the local copy is removed while the Dosya file remains available.
