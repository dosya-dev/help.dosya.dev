This guide covers **Inspect audio title and artist metadata** in Dosya. The main action is to open the audio viewer and details, compare title, artist, album, duration, and filename; the decisive check is whether the displayed tags belong to the selected audio file.

## Before you start

- Open the Dosya media viewer and File details in the current released client.
- Confirm the active account and workspace, then identify audio file with known embedded tags.

## Steps: inspect audio title and artist metadata

1. Open the Dosya media viewer and File details and confirm the active account and workspace.
2. Locate audio file with known embedded tags and verify its name or identifying details.
3. Open the audio viewer and details, compare title, artist, album, duration, and filename.
4. Confirm that the displayed tags belong to the selected audio file.

After completing the steps, check the expected result: The displayed tags belong to the selected audio file.

## Expected result

The controlled workflow completes and the displayed tags belong to the selected audio file.

## Troubleshooting

**The expected control is missing.** Return to the Dosya media viewer and File details, confirm the active workspace, and check that your role and client version support the action.
