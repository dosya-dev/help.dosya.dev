This guide covers **Filter activity by category** in Dosya. The main action is to select one or more categories and review the filtered count; the decisive check is whether only actions in the selected categories remain.

## Before you start

- Open Activity log in the current released client.
- Confirm the active account and workspace, then identify Category filter above the activity list.

## Steps: filter activity by category

1. Open Activity log and confirm the active account and workspace.
2. Locate Category filter above the activity list and verify its name or identifying details.
3. Select one or more categories and review the filtered count.
4. Confirm that only actions in the selected categories remain.

**Safety note.** You need the workspace activity permission; use the time and resource name to distinguish similar events.

## Verify the result

After completing the steps, check the expected result: Only actions in the selected categories remain.

## Expected result

The controlled workflow completes and only actions in the selected categories remain.

## Troubleshooting

**The expected control is missing.** Return to Activity log, confirm the active workspace, and check that your role and client version support the action.
