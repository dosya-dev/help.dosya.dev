This guide covers **Combine a folder scope with a file-type filter** in Dosya. The main action is to open or select the folder scope, apply the type filter, enter the search term, and review the active filters; the decisive check is whether results are limited to the intended folder context and file type.

## Before you start

- Open the Dosya file search in the current released client.
- Confirm the active account and workspace, then identify known parent folder and target file type.

## Steps: combine a folder scope with a file-type filter

1. Open the Dosya file search and confirm the active account and workspace.
2. Locate known parent folder and target file type and verify its name or identifying details.
3. Open or select the folder scope, apply the type filter, enter the search term, and review the active filters.
4. Confirm that results are limited to the intended folder context and file type.

## Verify the result

After completing the steps, check the expected result: Results are limited to the intended folder context and file type.

## Expected result

The controlled workflow completes and results are limited to the intended folder context and file type.

## Troubleshooting

**The expected control is missing.** Return to the Dosya file search, confirm the active workspace, and check that your role and client version support the action.
