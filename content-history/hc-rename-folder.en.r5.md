Check the workspace, folder path and identity of a test folder with a small file inside. Test a test folder with a small file inside with disposable data and compare source and destination after refreshing.

## Before you start

- Open Files → Rename in the current released Dosya client.
- Confirm the active account and workspace, then identify a test folder with a small file inside.

## Steps: rename a folder without losing contents

1. Open Files → Rename and confirm the active workspace.
2. Select a test folder with a small file inside and check its name or identifying details.
3. Change only the folder name and confirm.
4. Verify that the child file remains available under the new path.

**Safety note.** Use the destination picker to confirm the parent folder before saving.

## Verify the result

Verify that the child file remains available under the new path.

## Expected result

The workflow completes for the controlled test and the child file remains available under the new path.

## Troubleshooting

**The expected control is missing.** Return to Files → Rename, confirm the active workspace and check that your role permits the action.
