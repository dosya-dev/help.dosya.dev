This guide covers **Save a Vault file to the mobile device** in Dosya. The main action is to choose the save action and a trusted device destination; the decisive check is whether the decrypted copy is saved only where selected.

## Before you start

- Open Vault in the Dosya mobile app in the current released client.
- Confirm the active account and workspace, then identify Vault file approved for local storage.

## Steps: save a Vault file to the mobile device

1. Open Vault in the Dosya mobile app and confirm the active account and workspace.
2. Locate Vault file approved for local storage and verify its name or identifying details.
3. Choose the save action and a trusted device destination.
4. Confirm that the decrypted copy is saved only where selected.

## Verify the result

After completing the steps, check the expected result: The decrypted copy is saved only where selected.

## Expected result

The controlled workflow completes and the decrypted copy is saved only where selected.

## Troubleshooting

**The expected control is missing.** Return to Vault in the Dosya mobile app, confirm the active workspace, and check that your role and client version support the action.
