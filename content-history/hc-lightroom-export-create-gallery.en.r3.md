This guide covers **Create a client gallery during a Lightroom export** in Dosya. The main action is to enable gallery creation, set its title and access options, then export; the decisive check is whether dosya creates a dedicated export folder and a working gallery link.

## Before you start

- Open Lightroom Classic Export in the current released client.
- Confirm the active account and workspace, then identify gallery option in the Dosya Export dialog.

## Steps: create a client gallery during a Lightroom export

1. Open Lightroom Classic Export and confirm the active account and workspace.
2. Locate gallery option in the Dosya Export dialog and verify its name or identifying details.
3. Enable gallery creation, set its title and access options, then export.
4. Confirm that Dosya creates a dedicated export folder and a working gallery link.

## Verify the result

After completing the steps, check the expected result: Dosya creates a dedicated export folder and a working gallery link.

## Expected result

The controlled workflow completes and Dosya creates a dedicated export folder and a working gallery link.

## Troubleshooting

**The expected control is missing.** Return to Lightroom Classic Export, confirm the active workspace, and check that your role and client version support the action.
