This guide covers **Update the Dosya WordPress plug-in** in Dosya. The main action is to record settings, install the official update, and confirm the plug-in remains active; the decisive check is whether the updated plug-in retains its intended connection and can run a test backup.

## Before you start

- Open WordPress wp-admin and Integrations > WordPress and locate the installed Dosya backup plug-in and official current zip.
- Confirm the active account and workspace, then identify installed Dosya backup plug-in and official current zip.

## Steps: update the Dosya WordPress plug-in

1. Confirm the account and workspace in WordPress wp-admin and Integrations > WordPress when reviewing the installed Dosya backup plug-in and official current zip.
2. Locate installed Dosya backup plug-in and official current zip and verify its name or identifying details.
3. Record settings, install the official update, and confirm the plug-in remains active.
4. Confirm that the updated plug-in retains its intended connection and can run a test backup.

**Safety note.** Record the site URL, backup time, state, and nonsecret error before changing the connection.

## Verify the result

After completing the steps, check the expected result: The updated plug-in retains its intended connection and can run a test backup.

## Expected result

The controlled workflow completes and the updated plug-in retains its intended connection and can run a test backup.

## Troubleshooting

**The expected control is missing.** If the required control is missing for the installed Dosya backup plug-in and official current zip, check the active workspace, your role and the client version.
