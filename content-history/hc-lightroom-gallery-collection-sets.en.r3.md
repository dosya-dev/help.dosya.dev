This guide covers **Organize Lightroom galleries with collection sets** in Dosya. The main action is to name the set and collection, then publish the child collection; the decisive check is whether dosya mirrors the set and collection under the Lightroom folder hierarchy.

## Before you start

- Open Lightroom Classic Publish Services in the current released client.
- Confirm the active account and workspace, then identify published collection set and child collection.

## Steps: organize Lightroom galleries with collection sets

1. Open Lightroom Classic Publish Services and confirm the active account and workspace.
2. Locate published collection set and child collection and verify its name or identifying details.
3. Name the set and collection, then publish the child collection.
4. Confirm that Dosya mirrors the set and collection under the Lightroom folder hierarchy.

## Verify the result

After completing the steps, check the expected result: Dosya mirrors the set and collection under the Lightroom folder hierarchy.

## Expected result

The controlled workflow completes and Dosya mirrors the set and collection under the Lightroom folder hierarchy.

## Troubleshooting

**The expected control is missing.** Return to Lightroom Classic Publish Services, confirm the active workspace, and check that your role and client version support the action.
