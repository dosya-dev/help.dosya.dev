Use this workflow to remove a recipient from a file request in the intended account or workspace.

Removing a recipient stops that address from using recipient-specific request access, while previously submitted files remain in Dosya.

## Before you start

- Open File request recipients in the current released Dosya client.
- Confirm the active account and workspace, then identify one test recipient.

## Steps: remove a recipient from a file request

1. Open File request recipients and confirm the active workspace.
2. Select one test recipient and check its name or identifying details.
3. Remove access and confirm the change.
4. Verify that that recipient no longer appears as active.

## Verify the result

Refresh the recipient list and test the old invitation link when appropriate, confirming the removed recipient is no longer active.

## Expected result

The workflow completes for the controlled test and that recipient no longer appears as active.

## Troubleshooting

**The expected control is missing.** Return to File request recipients, confirm the active workspace and check that your role permits the action.
