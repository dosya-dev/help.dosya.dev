This guide covers **Reconnect an expired cloud import account** in Dosya. The main action is to choose Reconnect, approve the provider access, and return to Dosya; the decisive check is whether the provider picker loads again without creating an unnecessary second account entry.

## Before you start

- Open a connected Google Drive, OneDrive, or Dropbox import in the current released client.
- Confirm the active account and workspace, then identify provider connection that requests authorization again.

## Steps: reconnect an expired cloud import account

1. Open a connected Google Drive, OneDrive, or Dropbox import and confirm the active account and workspace.
2. Locate provider connection that requests authorization again and verify its name or identifying details.
3. Choose Reconnect, approve the provider access, and return to Dosya.
4. Confirm that the provider picker loads again without creating an unnecessary second account entry.

**Safety note.** Provider access is read for the selected import; verify the Dosya destination before starting.

## Verify the result

After completing the steps, check the expected result: The provider picker loads again without creating an unnecessary second account entry.

## Expected result

The controlled workflow completes and the provider picker loads again without creating an unnecessary second account entry.

## Troubleshooting

**The expected control is missing.** Return to a connected Google Drive, OneDrive, or Dropbox import, confirm the active workspace, and check that your role and client version support the action.
