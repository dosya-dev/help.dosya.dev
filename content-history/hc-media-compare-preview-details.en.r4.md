This guide covers **Compare preview metadata with File details** in Dosya. The main action is to compare filename, identifier, size, type, timestamps, and media-specific fields across both views; the decisive check is whether both views refer to the same stored file and current version.

## Before you start

- Open the Dosya media viewer and File details in the current released client.
- Confirm the active account and workspace, then identify media file open in both viewer and details panels.

## Steps: compare preview metadata with File details

1. Open the Dosya media viewer and File details and confirm the active account and workspace.
2. Locate media file open in both viewer and details panels and verify its name or identifying details.
3. Compare filename, identifier, size, type, timestamps, and media-specific fields across both views.
4. Confirm that both views refer to the same stored file and current version.

**Safety note.** Compare the preview with File details before relying on media metadata.

## Verify the result

After completing the steps, check the expected result: Both views refer to the same stored file and current version.

## Expected result

The controlled workflow completes and both views refer to the same stored file and current version.

## Troubleshooting

**The expected control is missing.** Return to the Dosya media viewer and File details, confirm the active workspace, and check that your role and client version support the action.
