This guide covers **Install the Dosya Lightroom Classic plug-in** in Dosya. The main action is to unzip the download, open File > Plug-in Manager, choose Add, and select dosya.lrplugin; the decisive check is whether the Plug-in Manager lists dosya.dev as installed and enabled.

## Before you start

- Open Lightroom Classic and Integrations > Lightroom Classic and locate the downloaded dosya.lrplugin folder.
- Confirm the active account and workspace, then identify downloaded dosya.lrplugin folder.

## Steps: install the Dosya Lightroom Classic plug-in

1. Confirm the account and workspace in Lightroom Classic and Integrations > Lightroom Classic when reviewing the downloaded dosya.lrplugin folder.
2. Locate downloaded dosya.lrplugin folder and verify its name or identifying details.
3. Unzip the download, open File > Plug-in Manager, choose Add, and select dosya.lrplugin.
4. Confirm that the Plug-in Manager lists dosya.dev as installed and enabled.

**Safety note.** Use Lightroom Classic 10 or newer and keep the plug-in folder in a permanent local location.

## Verify the result

After completing the steps, check the expected result: The Plug-in Manager lists dosya.dev as installed and enabled.

## Expected result

The controlled workflow completes and the Plug-in Manager lists dosya.dev as installed and enabled.

## Troubleshooting

**The expected control is missing.** If the required control is missing for the downloaded dosya.lrplugin folder, check the active workspace, your role and the client version.
