This guide covers **Export backed-up contacts as a vCard on mobile** in Dosya. The main action is to choose Export vCard and save it to a controlled destination; the decisive check is whether a VCF file is created for the selected contacts.

## Before you start

- Open Contacts backup in the Dosya mobile app in the current released client.
- Confirm the active account and workspace, then identify completed contacts backup.

## Steps: export backed-up contacts as a vCard on mobile

1. Open Contacts backup in the Dosya mobile app and confirm the active account and workspace.
2. Locate completed contacts backup and verify its name or identifying details.
3. Choose Export vCard and save it to a controlled destination.
4. Confirm that a VCF file is created for the selected contacts.

**Safety note.** Use a small test contact set and confirm the device contact account before restore.

## Verify the result

After completing the steps, check the expected result: A VCF file is created for the selected contacts.

## Expected result

The controlled workflow completes and a VCF file is created for the selected contacts.

## Troubleshooting

**The expected control is missing.** Return to Contacts backup in the Dosya mobile app, confirm the active workspace, and check that your role and client version support the action.
