Use this workflow to resend a file-request invitation in the intended account or workspace.

Resend only after checking the address, request status and recipient access. A new message does not change the request’s existing limits or destination.

## Before you start

- Open File request recipients in the current released Dosya client.
- Confirm the active account and workspace, then identify one pending test recipient.

## Steps: resend a file-request invitation

1. Open File request recipients and confirm the active workspace.
2. Select one pending test recipient and check its name or identifying details.
3. Choose Resend and confirm the address.
4. Verify that the recipient status reflects the new delivery attempt.

**Safety note.** Use a test recipient and confirm the receiving folder before sending a request.

## Verify the result

Confirm the recipient row records the new delivery attempt and that the request link still opens with the intended settings.

## Expected result

The workflow completes for the controlled test and the recipient status reflects the new delivery attempt.

## Troubleshooting

**The expected control is missing.** Return to File request recipients, confirm the active workspace and check that your role permits the action.
