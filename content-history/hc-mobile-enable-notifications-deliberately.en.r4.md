This guide covers **Enable mobile notifications deliberately** in Dosya. The main action is to allow notifications only for the intended account, review alert style, and trigger or await a controlled event; the decisive check is whether the device can display the selected Dosya notification types.

## Before you start

- Open the Dosya mobile app and device settings in the current released client.
- Confirm the active account and workspace, then identify Dosya notification prompt and device notification settings.

## Steps: enable mobile notifications deliberately

1. Open the Dosya mobile app and device settings and confirm the active account and workspace.
2. Locate Dosya notification prompt and device notification settings and verify its name or identifying details.
3. Allow notifications only for the intended account, review alert style, and trigger or await a controlled event.
4. Confirm that the device can display the selected Dosya notification types.

**Safety note.** Grant each operating-system permission only when its related feature is needed.

## Verify the result

After completing the steps, check the expected result: The device can display the selected Dosya notification types.

## Expected result

The controlled workflow completes and the device can display the selected Dosya notification types.

## Troubleshooting

**The expected control is missing.** Return to the Dosya mobile app and device settings, confirm the active workspace, and check that your role and client version support the action.
