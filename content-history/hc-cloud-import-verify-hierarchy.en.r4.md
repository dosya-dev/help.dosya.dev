This guide covers **Verify imported folder hierarchy** in Dosya. The main action is to open each expected level and compare representative files with the provider tree; the decisive check is whether the imported hierarchy preserves the planned structure.

## Before you start

- Open a completed or partially completed cloud import in the current released client.
- Confirm the active account and workspace, then identify known nested source folder and its Dosya destination.

## Steps: verify imported folder hierarchy

1. Open a completed or partially completed cloud import and confirm the active account and workspace.
2. Locate known nested source folder and its Dosya destination and verify its name or identifying details.
3. Open each expected level and compare representative files with the provider tree.
4. Confirm that the imported hierarchy preserves the planned structure.

**Safety note.** Compare the result with the provider source before disconnecting the account.

## Verify the result

After completing the steps, check the expected result: The imported hierarchy preserves the planned structure.

## Expected result

The controlled workflow completes and the imported hierarchy preserves the planned structure.

## Troubleshooting

**The expected control is missing.** Return to a completed or partially completed cloud import, confirm the active workspace, and check that your role and client version support the action.
