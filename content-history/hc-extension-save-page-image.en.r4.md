This guide covers **Save a specific webpage image to Dosya** in Dosya. The main action is to confirm the image preview and source, choose the destination, and save it once; the decisive check is whether the intended image appears in the selected folder.

For the selected webpage image, keep the browser profile, account, site permission and destination folder visible.

## Before you start

- Open the Save to Dosya browser extension in the current released client.
- Confirm the active account and workspace, then identify image selected from a page and the extension save panel.

## Steps: save a specific webpage image to Dosya

1. Open the Save to Dosya browser extension and confirm the active account and workspace.
2. Locate image selected from a page and the extension save panel and verify its name or identifying details.
3. Confirm the image preview and source, choose the destination, and save it once.
4. Confirm that the intended image appears in the selected folder.

**Safety note.** Review the captured preview and destination before saving private web content.

## Verify the result

After completing the steps, check the expected result: The intended image appears in the selected folder.

Compare the selected webpage image in Dosya with the original browser content. If the selected webpage image is missing or incorrect, check the browser profile, site permission, extension session and destination error.

## Expected result

The controlled workflow completes and the intended image appears in the selected folder.

## Troubleshooting

**The expected control is missing.** Return to the Save to Dosya browser extension, confirm the active workspace, and check that your role and client version support the action.
