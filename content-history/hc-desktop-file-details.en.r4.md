This guide covers **Open file details in the desktop app** in Dosya. The main action is to open Details and review metadata, location, version, and available actions; the decisive check is whether the panel describes the selected file.

## Before you start

- Open the Dosya desktop app and locate the file selected in the desktop library.
- Confirm the active account and workspace, then identify file selected in the desktop library.

## Steps: open file details in the desktop app

1. Confirm the account and workspace in the Dosya desktop app when reviewing the file selected in the desktop library.
2. Locate file selected in the desktop library and verify its name or identifying details.
3. Open Details and review metadata, location, version, and available actions.
4. Confirm that the panel describes the selected file.

**Safety note.** Open untrusted archives or documents only after checking their source and filename.

## Verify the result

After completing the steps, check the expected result: The panel describes the selected file.

## Expected result

The controlled workflow completes and the panel describes the selected file.

## Troubleshooting

**The expected control is missing.** If the required control is missing for the file selected in the desktop library, check the active workspace, your role and the client version.
