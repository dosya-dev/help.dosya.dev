This guide covers **Republish Lightroom edits without duplicate gallery items** in Dosya. The main action is to publish the modified photo again and wait for the update to complete; the decisive check is whether the existing Dosya file gains a version and the gallery keeps one item for the photo.

## Before you start

- Open Lightroom Classic Publish Services in the current released client.
- Confirm the active account and workspace, then identify photo listed under Modified Photos to Re-Publish.

## Steps: republish Lightroom edits without duplicate gallery items

1. Open Lightroom Classic Publish Services and confirm the active account and workspace.
2. Locate photo listed under Modified Photos to Re-Publish and verify its name or identifying details.
3. Publish the modified photo again and wait for the update to complete.
4. Confirm that the existing Dosya file gains a version and the gallery keeps one item for the photo.

## Verify the result

After completing the steps, check the expected result: The existing Dosya file gains a version and the gallery keeps one item for the photo.

## Expected result

The controlled workflow completes and the existing Dosya file gains a version and the gallery keeps one item for the photo.

## Troubleshooting

**The expected control is missing.** Return to Lightroom Classic Publish Services, confirm the active workspace, and check that your role and client version support the action.
