This guide covers **Review per-client selection collections in Lightroom** in Dosya. The main action is to open the collection named for the test client and compare it with the web gallery; the decisive check is whether the collection contains the photos selected by that client.

## Before you start

- Open Lightroom Classic and the published Dosya gallery in the current released client.
- Confirm the active account and workspace, then identify dosya client selections collection set.

## Steps: review per-client selection collections in Lightroom

1. Open Lightroom Classic and the published Dosya gallery and confirm the active account and workspace.
2. Locate dosya client selections collection set and verify its name or identifying details.
3. Open the collection named for the test client and compare it with the web gallery.
4. Confirm that the collection contains the photos selected by that client.

**Safety note.** Ask clients to use a clear display name so their selection collection is recognizable.

## Verify the result

After completing the steps, check the expected result: The collection contains the photos selected by that client.

## Expected result

The controlled workflow completes and the collection contains the photos selected by that client.

## Troubleshooting

**The expected control is missing.** Return to Lightroom Classic and the published Dosya gallery, confirm the active workspace, and check that your role and client version support the action.
