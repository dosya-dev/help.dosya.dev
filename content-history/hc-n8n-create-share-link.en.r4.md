## Before you start

- Open Zapier or n8n with Dosya in the current released client.
- Confirm the active account and workspace, then identify test workflow with a known Dosya file.

## Steps: build an n8n workflow that creates a Dosya share link

1. Open Zapier or n8n with Dosya and confirm the active account and workspace.
2. Locate test workflow with a known Dosya file and verify its name or identifying details.
3. Add the Dosya sharing operation, map the file ID and safe options, then execute once.
4. Confirm that the workflow returns a working link for the test file.
