## Before you start

- Open the Dosya mobile file browser and search in the current released client.
- Confirm the active account and workspace, then identify multiple mobile results with the same name.

## Steps: open a same-named mobile search result safely

1. Open the Dosya mobile file browser and search and confirm the active account and workspace.
2. Locate multiple mobile results with the same name and verify its name or identifying details.
3. Compare workspace, folder, size, modified time, and preview before using a result.
4. Confirm that the opened item is the intended same-named file.

## Verify the result

After completing the steps, check the expected result: The opened item is the intended same-named file.

## Expected result

The controlled workflow completes and the opened item is the intended same-named file.

## Troubleshooting

**The expected control is missing.** Return to the Dosya mobile file browser and search, confirm the active workspace, and check that your role and client version support the action.
