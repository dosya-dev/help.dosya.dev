This guide covers **Review WordPress backup status** in Dosya. The main action is to compare last backup, stored size, state, and protection time; the decisive check is whether the newest backup state and retention context are clear.

## Before you start

- Open WordPress wp-admin and Integrations > WordPress and locate the connected site row in Integrations > WordPress.
- Confirm the active account and workspace, then identify connected site row in Integrations > WordPress.

## Steps: review WordPress backup status

1. Confirm the account and workspace in WordPress wp-admin and Integrations > WordPress when reviewing the connected site row in Integrations > WordPress.
2. Locate connected site row in Integrations > WordPress and verify its name or identifying details.
3. Compare last backup, stored size, state, and protection time.
4. Confirm that the newest backup state and retention context are clear.

## Verify the result

After completing the steps, check the expected result: The newest backup state and retention context are clear.

## Expected result

The controlled workflow completes and the newest backup state and retention context are clear.

## Troubleshooting

**The expected control is missing.** If the required control is missing for the connected site row in Integrations > WordPress, check the active workspace, your role and the client version.
